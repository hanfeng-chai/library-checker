# 静态区间逆序对

`main.cxx` 调用 inversions.h。稳定排序后的唯一秩保留相等值的原下标顺序，
因此相等元素不会被误计为逆序。区间答案写成前缀逆序数之差加上跨边界修正。

按莫队顺序移动查询端点，把修正项变成某个数组前缀下的一段秩计数事件。
随后只从左到右扫描原数组一次，使用“秩前缀加一、单点读取”计数器完成事件，
再沿莫队次序累加差分。事件按扫描位置连续分组；AVX2 gather 合并细计数与
块懒标记，拓宽到 u64 累加。与位置有关的线性项直接用等差数列公式求和。

GCC/Clang 官方、重复值/空区间/高位 u32/各种端点移动的朴素对照和 sanitizer 通过。
Lenovo 单次 max/sum 为 109.210/584.012 ms，参考最小值为 186.363/956.759 ms。
证据：bench/ds-adaptive-20261001/round1/。旧 .cpp 保留作参考。
