# 区间并查集

`main.cxx` 使用 parallel_dsu.h 的八叉分层并查集。第 k 层记录长度 8^k 的
区间是否逐位置等价，首次合并时才下钻到八个子区间。查询长度用至多八个
最长的幂次区间覆盖，重叠部分由并查集自动跳过。

每次底层合并两个连通块，新增跨块点对的贡献是两个块权值和之积；将其计入
答案，再合并权值和。底层回调最多 n−1 次，已有连通块内的点对不会重复计数。

相比二叉，八叉减少了层数、内存和查找路径。GCC/Clang 官方及逐元素对照、
sanitizer 通过。Lenovo 单次 max/sum 为 506.116/5467.354 ms，参考最小值为
726.199/8113.444 ms。证据：bench/ds-adaptive-20261001/round1/selected-parallel/。
旧 .cpp 保留作参考。
