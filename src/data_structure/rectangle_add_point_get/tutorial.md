# 矩形加、单点查询

`main.cxx` 使用 rectangle_add_point.h 离线计算。查询记录此前矩形数量 t，
把 [0,t) 分成 lowbit 时间块。对每块扫描矩形的左右 x 事件，在 y 方向做差分
Fenwick 更新；查询只累加属于自己时间前缀的块，所以保持原操作顺序的语义。

更新端点渐进归并；查询首次基数排序，再沿时间块分发并保持有序。
首次查询之前的大块直接排序，避免为无人查询的小块反复合并。
一次矩形边事件的两次 Fenwick 更新符号相反，到共同祖先便停止。
空间 O(N+Q)，保守时间 O((N+Q) log²(N+1))。

19 个官方测例通过 GCC/Clang，负权、半开边界、空矩形和历史操作通过朴素对照
及 ASan/UBSan。Lenovo 静默、不绑核、每例一次：main max/sum 为
252.523/1913.444 ms，五份参考的最小值分别为 293.146/2389.745 ms。
证据：bench/ds-beats-prefix-20261001/round1/selected/。
旧 .cpp 保留为参考；当前主解不使用二维 Wavelet 的在线更新。

## 尝试过程与取舍

首版二维结构之后，尝试按时间块做离线扫描。矩形端点渐进归并，查询保持有序分发；随后让符号相反的 Fenwick 更新在共同祖先抵消，跳过首次查询前无人使用的小时间块。每步都保持历史操作前缀的语义，不把未来矩形计入过去查询。
