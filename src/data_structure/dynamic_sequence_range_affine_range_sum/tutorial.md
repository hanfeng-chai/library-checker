# 动态序列、区间仿射与区间和

`main.cxx` 使用 rope.h 的 Rope<998244353>，与区间反转题共享叶子分块平衡树。
内部节点缓存长度与和，完整区间的仿射更新只改变和及懒标记；边界叶子用
AVX2 每次映射八个值。普通余数的和与 Montgomery 编码的标记混合计算，
避免每层重新编码和解码。

反转与仿射变换可交换，因此局部反转保留标记，只调整物理区间。
删除无需物化整个叶子，只从总和扣除该元素经过当前映射后的值。
插入先物化叶子的仿射标记，按方向映射位置；查询则携带祖先变换，保持只读。
边界修复、合并和反转都复用捕获的路径，避免反复拆树。

33 个官方测例通过 GCC/Clang；三种模数下的独立数组对照、零斜率、池扩容、
树高与块装载量检查通过 ASan/UBSan。
Lenovo 静默、不绑核、每例一次：main max/sum 为 1112.762/8606.438 ms，
五份参考的最小值分别为 1183.763/8906.449 ms。
证据：bench/ds-rope-20261001/round2/selected/。旧 .cpp 保留作参考。

## 尝试过程与取舍

从节点式序列结构出发，比较 512/256 分块、边界直接处理、元数据分离与扁平布局，再改为叶子分块 Rope。最后让叶子的物理方向继续由标记表示，删除和局部反转不先物化整块。反转、仿射更新和只读查询共用捕获的边界路径；与区间反转求和题一起回归。
