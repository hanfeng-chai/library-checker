# 插入直线、单点最小值

`main.cxx` 先收集并压缩所有查询坐标。初始直线用 line_hull.h 一次建立下包络，
按坐标递增扫描，填入每个查询位置的初始最小值；这样不必逐条插入初始直线。
后续插入仍按时间顺序进入 li_chao.h，查询取初始最小值与新增直线候选的最小值。

下包络按斜率递减排序，用 i128 比较交点次序，删除永不最优的线。
Li Chao 利用两条线优势最多交换一次的性质，在两端和中点剪枝，只下降可能反超
的一侧。查询坐标排序时直接写回操作下标，执行阶段不做二分映射。

初始包络在固定宽度基数排序后线性构造；后续操作 O(log Q)，空间 O(N+Q)。
GCC/Clang 官方、下包络与 Li Chao 独立朴素对照及 sanitizer 通过。
最终共享头文件下，Lenovo 单次 max/sum 为 76.807/610.084 ms，参考最小值为
135.666/813.754 ms。证据：bench/ds-confirm-20261001/round1/。旧 .cpp 保留作参考。
