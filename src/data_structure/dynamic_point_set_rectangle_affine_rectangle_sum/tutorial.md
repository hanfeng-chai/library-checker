`main.cxx` 预读未来插入坐标，用 kd_affine.h 的 AffineKDTree 建树，然后按原顺序
执行操作。叶子保存至多 64 个点，内部节点维护包围盒、活动点数、权和和仿射标记。
完整覆盖时 sum ← a·sum+b·active_count；不交时跳过，部分相交时才继续下降。

与旧 lazy_kd_tree.cpp 的每节点一个点不同，主解把节点与点的坐标、权重数组分开。
叶子用 AVX2 每次筛选八点。只读查询携带祖先变换；部分更新将旧标记和新变换合并，
一次扫描物化叶子。和为普通余数，标记为 Montgomery 编码。

默认交替按坐标中位数切分。极低基数的一维先合并相同坐标，再切另一维，避免
狭长、少坐标数据的无效遍历。该选择依赖坐标基数，不依赖数值跨度。
插入前下传路径上的旧标记，再激活目标点；过去的更新因此不会作用到未来点。

空间 O(N)，单点更新 O(log N+64)，矩形操作按实际访问节点与边界叶子计费，
最坏仍可能扫描 O(N)。不能仅凭平衡高度保证任意分布的矩形查询效率。
25 个官方测例通过 GCC/Clang，未来激活、零斜率、重复坐标等通过朴素对照及 sanitizer。

## 尝试过程与取舍

首版 kd-tree 每个节点保存一个点，后改为内部包围盒加最多 64 点的叶子桶。叶子统一 SIMD 筛选、应用变换；只读查询携带祖先标记，插入前先下传旧标记，防止旧更新影响未来点。针对坐标基数很小的情况调整切分方向，选择依据来自输入坐标结构。
