# 前驱与后继

主解使用 [BitSet](../../../docs/bitset.md) 的分层位图：高层标记低层非空字，
当前字内无答案时向上寻找邻近的非空字，再向下定位。
集合不超过 16 个元素时缓存有序键，用 SIMD 求秩；修改后再刷新。
主解合并前驱/后继的查询方向，较大集合的字内查询也采用无分支选择。

GCC/Clang 官方、随机边界对照及 sanitizer 通过。
Lenovo 单次 max/sum 为 32.139/311.515 ms，对照最小值为 33.554/324.676 ms。
证据：`bench/ds-last-basic-20260930/round1/selected/`。旧 .cpp 保留作参考。
