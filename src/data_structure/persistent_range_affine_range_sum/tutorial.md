# 可持久化区间仿射更新、复制与求和

`main.cxx` 使用 persistent_affine.h 的路径复制线段树。每个根表示一个不可变版本，
更新只创建边界路径及必要的新标记节点，完整子树尽量共享；区间复制分别携带
目标与源版本的祖先变换，避免混淆两个版本的懒标记。查询不创建节点。

区间和使用普通余数，仿射标记使用 Montgomery 编码。递归查询先合并孩子中
交集的和，再按实际交集长度应用当前标记；混合乘加可一次规约。
所有操作 O(log N)，q 次修改后的总空间 O(N+Q log N)。

GCC/Clang 官方、旧版本/复制/零斜率/小模数/空区间/扩容朴素对照及 sanitizer 通过。
Lenovo 单次 max/sum 为 275.606/1659.253 ms，五份参考最小值为 293.391/2197.730 ms。
证据：bench/ds-persistent-mode-20261001/round1/。旧 .cpp 保留作参考。
