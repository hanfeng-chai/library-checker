# 集合异或最小值

`main.cxx` 使用 xor_set.h 的分块位图，键范围为 30 位。一个块覆盖 512 个键，
目录直接保存单元素，只有发生碰撞才分配位图。占用索引逐层选择使异或结果最小
的高位前缀；同一叶中先选字，再选位。异或值由最高不同位决定，因此每层优先
匹配查询位的贪心选择正确。插入重复值和删除不存在值均不改变集合。

`naive.cxx` 保留空间随集合增长的压缩字典树方案，测试通用 u32 集合接口。
主解在本题的已知值域下避免了长链随机访存。

GCC/Clang 官方、完整 u32 随机对照及 sanitizer 通过。
Lenovo 单次 max/sum 为 44.192/335.239 ms，五份参考最小值为 47.250/359.506 ms。
证据：bench/ds-wide-20261001/round1/。

## 尝试过程与取舍

先保留按集合规模增长的 Patricia 压缩字典树，再利用本题 30 位值域测试分块位图。目录直接存单元素，碰撞时才创建位图，减少长链随机访存。最终主解采用分块位图，通用 u32 的经典压缩字典树保留为 naive.cxx。
