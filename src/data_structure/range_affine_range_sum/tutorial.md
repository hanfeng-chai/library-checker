# 区间仿射、区间求和

`main.cxx` 使用 affine_range_sum.h 的 16 叉懒线段树。和保留普通余数，标记
使用 Montgomery 编码；每个内部节点的和与两组标记相邻存放，减少分散访存。
AVX2 同时更新八个孩子，固定斜率的商预先计算，供多次 Shoup 规约复用。

完整覆盖直接更新聚合和标记；部分覆盖沿边界下传，叶子的旧标记与新更新
融合为一次扫描。查询携带局部覆盖长度向上应用标记，保持只读。
主解先按顺序读入操作，再按原顺序执行并提前四次操作预取地址；初值和更新
系数使用 read_pair<9>()，预读不改变更新和查询的语义。

19 个官方测例通过 GCC/Clang；模数 17 和 998244353 下的零乘数、恒等变换、
空区间及多层边界通过朴素数组对照与 ASan/UBSan。
Lenovo 静默、不绑核、每例一次：main max/sum 为 205.814/1078.654 ms，
五份参考的最小值分别为 210.199/1106.809 ms。
证据：bench/ds-sum-packed-20261001/round2/selected/。旧 .cpp 保留作参考。

## 尝试过程与取舍

先从普通懒标记树比较宽节点、二叉布局和节点压紧，继续测试不同规约方式、成对处理、分层存储与预取。后期将边界标记的传递、运算融合和循环展开分别测量，再结合输入读取优化。保持和为普通余数、标记为 Montgomery 表示；反复实验说明更宽或更紧并非自动更快，最终按完整 max/sum 选组合。
