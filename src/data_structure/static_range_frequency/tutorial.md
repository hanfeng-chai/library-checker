# 静态区间频次

主解把每次查询拆成右端点前缀频次减左端点前缀频次，按端点位置分桶。
顺序扫描数组，用哈希表维护已出现的次数，在端点处累加对应贡献。
因此总期望时间 O(n+q)、空间 O(n+q)，避免对高频值的长位置表反复二分。

接口见 [frequency](../../../docs/frequency.md)，仍提供按出现位置二分的在线接口。
GCC/Clang 官方、独立对照及 sanitizer 通过。Lenovo 单次 max/sum 为
112.421/570.839 ms，对照最小值为 124.184/622.398 ms。
证据：`bench/ds-basic-20260930/round2/`。旧 .cpp 实现保留作参考。
