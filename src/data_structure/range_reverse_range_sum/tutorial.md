# 区间反转、区间求和

`main.cxx` 使用 rope.h 的 Rope<>。u32 数据按块放在叶子里，内部节点缓存长度
和 u64 和；反转整段只交换孩子与方向标记，求和沿两条边界读取。

局部反转同时定位两个边界块，将区间外侧的片段反向交换，再翻转整块区间。
保存的下降路径用于重建，复用内部节点。叶子的物理方向继续用标记表示，
无需为编辑小片段先反转完整叶子。只有新块长度不合适时才切分并修复装载量。
树允许孩子高度差至多 4，默认块容量 512，空间为 O(N)。

20 个官方测例通过 GCC/Clang；独立数组对照检查插入、删除、反转、和、树高、
叶子装载量及缓存边界，ASan/UBSan 通过。
Lenovo 静默、不绑核、每例一次：main max/sum 为 367.677/1997.357 ms，
五份参考的最小值分别为 399.217/2039.766 ms。
证据：bench/ds-rope-20261001/round2/selected/。旧 .cpp 保留作参考。
