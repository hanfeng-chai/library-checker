# 可持久化队列

离线将每个操作挂到其基础版本下，用 [VersionTree](../../../docs/version_tree.md) 遍历。
进入节点时在连续缓冲中移动队首或队尾；离开时恢复指针，并把被弹出的值写回原位置。
每个版本只访问一次，O(q) 时间和空间；答案另按输入次序保存。

显式栈避免深递归。版本邻接表与操作记录使用大页提示降低随机访问的地址转换开销，
普通队列和答案缓冲保持原样。GCC/Clang 官方、版本树边界与 sanitizer 已通过。
Lenovo 单次 max/sum 为 48.342/307.615 ms，对照最小值为 55.973/362.113 ms。
证据：`bench/ds-last-basic-20260930/round1/selected/`。旧 .cpp 保留作参考。
