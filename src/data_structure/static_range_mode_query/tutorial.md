# 静态区间众数

`main.cxx` 使用 mode.h，按数组的实际不同值数量与最高频率选择精确算法。
小值域先直接哈希编号；若超过阈值则回到基数排序，避免为大量重复值重复排序。

两种值时用一个标量前缀计数；稠密小值域用块前缀计数和 AVX2 最大值比较。
总频率较低时，表中保存“从左端点以后开始，k 次相同值最早在哪结束”，据此
二分频次。其余数组用完整块众数与两端出现位置验证。没有随机抽样或近似答案。

GCC/Clang 官方、各策略与切换边界朴素对照、sanitizer 均通过。
Lenovo 单次 max/sum 为 38.856/113.454 ms，参考最小值为 43.699/121.800 ms。
证据：bench/ds-flat-20261001/round1/selected-mode/。旧 .cpp 保留作参考。
