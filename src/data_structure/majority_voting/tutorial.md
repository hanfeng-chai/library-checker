# 动态区间多数票

`main.cxx` 用 majority.h 的线段树得到区间候选，再用 offline_frequency.h
精确验证出现次数是否严格超过区间长度的一半。不同元素成对抵消不会删光严格
多数，所以候选不会漏掉真正的多数；没有多数时则由计数拒绝，输出 -1。
剩余票数不是出现次数，不能直接用于最后的判断。

值通过哈希映射压缩。每次修改生成旧值移除、新值加入两个频率事件，查询生成
候选值的区间计数事件。按值稳定分组后依次在同一份位图与宽前缀树上处理，
保留修改和查询的时间顺序。每组结束按最终状态清空位图，供下一组使用。

总时间 O((N+Q)log N)，空间 O(N+Q)。GCC/Clang 官方、朴素多数与动态计数
对照及 sanitizer 通过。Lenovo 单次 max/sum 为 325.455/1821.534 ms，
参考最小值为 341.857/1933.153 ms。证据：bench/ds-frequency-20261001/round1/。
旧 .cpp 保留作参考。
