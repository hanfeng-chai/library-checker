# 线段插入、单点最小值

`main.cxx` 将查询坐标与线段两端一起基数排序，直接为所有查询和端点确定下标。
只有真正查询过的坐标进入树；即使端点等于查询坐标，也按 [l,r) 的定义处理。

li_chao.h 把一个线段分成二叉树上的完整子区间，再在每个子区间插入该直线。
插入利用两条直线只会交换一次优势的性质，以两端、中点剪枝，只下降可能反超
的一侧。查询沿叶到根求候选直线最小值；没有覆盖候选时输出 INFINITY。
插入 O(log² Q)，查询 O(log Q)，空间 O(N+Q)。

沿用了旧索引式实现的端点剪枝，用位枚举跳过区间分解中没有贡献的层。
GCC/Clang 官方、重复坐标/极端坐标朴素对照及 sanitizer 通过。
Lenovo 单次 max/sum 为 138.819/918.612 ms，参考最小值为 151.618/1002.046 ms。
证据：bench/ds-tree-final-20261001/round1/selected-segment/。旧 .cpp 保留作参考。
