# 超大数组单点赋值、区间函数复合

`main.cxx` 只为发生修改的位置建立叶子，其他位置一直是恒等函数，可直接省去。
修改坐标与查询端点一起基数排序，将每个端点映射为“严格小于它的修改位置数”，
于是原区间 [l,r) 与压缩后的函数区间完全对应，执行阶段无需二分查找。

`affine_tree.h` 使用反向叶子的紧凑二叉树。内部斜率为 Montgomery 编码、
截距为普通余数，查询直接应用各完整子区间函数。没有修改时直接输出查询的 x，
没有查询时无需构建树。时间 O(Q log Q)，空间 O(Q)。

GCC/Clang 全部官方检查通过，底层库的零斜率/空区间/非二次幂对照与 sanitizer 通过。
Lenovo 单次 max/sum 为 180.900/2650.230 ms，参考最小值为 186.531/2690.536 ms。
证据：bench/ds-composite-mont-20261001/round1/selected/。旧 .cpp 保留作参考。
