# 单点修改、区间函数复合

题目保证斜率非零，`main.cxx` 因此使用 affine_prefix.h 的逆前缀树。
令 G_i=f_{i-1}∘…∘f_0，区间结果为 G_r∘G_l⁻¹(x)。保存逆前缀后，查询可写成
(G_l⁻¹(x)−G_r⁻¹(0))/slope(G_r⁻¹)，返回一个分数即可。

先读完操作，批量求出所有新斜率的逆，再按位置历史算出 new⁻¹∘old 的纠正。
随后仍按原顺序更新和查询，最后批量求逆还原分数答案。没有重排实际操作。
16 叉节点用 AVX2 修改后缀前缀值，缓存各层基址，并提前预取下一批操作的位置。

更新参数和相邻输入使用 read_pair<9>()：统一寻找两个分隔符，每个整数末尾
八位放入一个 u64 通道归约，第九位单独加回；读取不会越过文件开头。

16 个官方测例通过 GCC/Clang，非零斜率、空范围、节点边界及数字宽度的朴素
对照与 ASan/UBSan 通过。Lenovo 静默、不绑核、每例一次：main max/sum 为
102.341/797.098 ms，五份参考的最小值分别为 103.111/801.585 ms。
优势约 0.75%/0.56%，不是每个测例都更快。
证据：bench/ds-affine-final-20261001/round1/selected/。旧 .cpp 保留作参考。

## 尝试过程与取舍

从通用二叉复合树出发，比较宽前缀、展开、成对计算和输出路径。再尝试 Montgomery、SIMD、八叉布局、分层存储、预取与预备操作记录，逐步缩小热路径和节点宽度。该题不交换，所有优化都必须保留左右复合顺序；下表保留单项获益却未同时达到 max/sum 门槛的阶段。
