`main.cxx` 使用 linear_min.h 的 Kinetic 线段树。第 i 个数对应关于累积斜率的
直线 y=a_i+i·t；每个节点记录当前获胜下标和到下一次可能换胜者的双向距离。
完整区间增加 b·i+c 时，若 b 未越过安全距离，最小值直接增加 b·index+c；
否则下降更新，再由孩子的安全距离与两条候选直线交点重算。

安全距离同时考虑两个子树，因此安全更新可直接向孩子传递，不必再次搜索。
查询携带祖先累积的斜率与常数，保持只读。空间 O(N)，查询 O(log N)，
更新最坏 O(N)；反复相反斜率的操作可能多次触发大量失效节点。

28 个官方测例通过 GCC/Clang，正负更新、交替斜率等通过朴素对照及 ASan/UBSan。

## 尝试过程与取舍

先建立线性区间更新与最小值的基线，随后采用 Kinetic 线段树，记录当前胜者及双向安全距离。安全更新直接传递，越过交点才下降修复；后续针对叶子和相反斜率抵消继续优化。保留最坏更新可能线性的说明，并用交替斜率作独立对照。
