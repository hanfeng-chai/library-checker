# 区间加、区间最小值

`main.cxx` 使用 range_add_min.h 的八叉树。每个孩子保存相对父区间最小值的差，
因此同一节点内最小差恒为零，整树最小值另外保存。完整孩子区间加只改对应的差；
局部修改后重新归一化，并把最小值变化传给父层。这相当于把懒标记融入坐标系，
无需向下推区间加标记。

AVX2 同时更新八个 i64 差值，查询折叠两条边界路径并累加祖先差。
整数组加直接更新根偏移。操作预先读入紧凑记录，执行仍按原顺序，并预取四步
之后的边界节点。时间 O((N+Q)log N)，空间 O(N+Q)。

GCC/Clang 官方、空区间与随机正负增量朴素对照及 sanitizer 通过。
Lenovo 单次 max/sum 为 133.911/1171.009 ms，参考最小值为 135.192/1174.274 ms。
两项优势较小，不应解释为所有测例都更快。证据：bench/ds-confirm-20261001/round1/selected/。
