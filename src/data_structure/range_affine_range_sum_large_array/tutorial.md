# 超大数组区间仿射更新与求和

`main.cxx` 收集全部操作端点与 0、N，基数排序后直接将端点写回操作记录。
相邻端点间的每个原位置始终接受相同的更新，因此可压成一个带长度的叶子。
weighted_affine.h 保留原区间长度，平移 b 对节点和的贡献是 b×长度。

和用普通余数，懒标记用 Montgomery 编码；查询返回孩子局部和后，再按实际
交集长度应用父标记，避免为查询下推。每次操作 O(log Q)，空间 O(Q)。

GCC/Clang 官方、完整 u32 跨度/重复端点/非零初值/小模数/空区间对照及 sanitizer 通过。
Lenovo 单次 max/sum 为 145.717/1931.802 ms，参考最小值为 171.264/1995.688 ms。
证据：bench/ds-large-20261001/round1/。旧 .cpp 保留作参考。
