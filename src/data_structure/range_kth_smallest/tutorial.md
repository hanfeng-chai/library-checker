# 区间第 k 小

`main.cxx` 使用 `offline_kth.h`：先压缩值域，再逐位稳定划分全部值。
每一层同时处理全部查询，仅保存当前层 u32 前缀计数和两份元素数组。
查询先由前缀计数求区间零元素数，再选择零或一分组，更新 l、r、k。
稳定划分保持组内顺序，故映射后的查询与原查询等价，逐层归纳得到第 k 小值。

AVX2 每次稳定划分八个元素并更新八个查询；最后一位直接恢复原值，避免逐层
写答案数组。总复杂度 O((N+Q) log S)，额外空间 O(N+Q)，S 为不同值数。
在线接口 `wavelet.h` 保存各层位图，可用于查询无法预先读入的场景。

GCC/Clang 官方、全 u32 值域与 SIMD 尾部朴素对照及 sanitizer 通过。
Lenovo 单次 max/sum 为 43.316/346.724 ms，五份参考中的最小值为
44.449/359.333 ms。证据：bench/ds-segment-20261001/round1/。旧 .cpp 保留作参考。
