`main.cxx` 使用 `offline_kth.h`：先压缩值域，再逐位稳定划分全部值。
每一层同时处理全部查询，仅保存当前层前缀计数和两份元素数组。
分散的大批查询用四个位置共用一个 u32 的前缀包，将工作集缩到四分之一；
小输入、集中端点或超出 24 位计数范围时保留普通前缀。
查询先由前缀计数求区间零元素数，再选择零或一分组，更新 l、r、k。
稳定划分保持组内顺序，故映射后的查询与原查询等价，逐层归纳得到第 k 小值。

AVX2 每次稳定划分八个元素并更新八个查询；最后一位直接恢复原值，避免逐层
写答案数组。总复杂度 O((N+Q) log S)，额外空间 O(N+Q)，S 为不同值数。
在线接口 `wavelet.h` 保存各层位图，可用于查询无法预先读入的场景。

GCC/Clang 官方、全 u32 值域与 SIMD 尾部朴素对照及 sanitizer 通过。

## 尝试过程与取舍

先保留在线 WaveletMatrix，再利用查询全部已知的条件逐位离线处理。每层同时稳定划分全部元素并更新所有查询，减少保存每层位图与随机查询的开销；后续优化 SIMD 划分、尾部和最后一位答案恢复。在线经典版本保留在 naive.cxx。

重新核实后，原实现 max 45.156 ms，nandhagk 为 43.742 ms，差距仍在。
压缩前缀工作集后，两项达到顶部列出的目标；三轮十一位基数排序没有整体收益，
保留原排序。正式产物与候选 SHA-256 完全一致，直接复用候选两轮记录；
参考提交和 naive 沿用初始全量评测，来源与 binary 哈希列在 bench.txt 中。
