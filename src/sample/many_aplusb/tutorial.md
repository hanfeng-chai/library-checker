# 大量 64 位整数加法

本题主要测输入和输出。main.cxx 用 read<u64,19>() 读取两个非负数，每 2048 项
缓存结果，再批量写出。输入位数提示限定合法范围；程序仍处理不同长度和分布。
加法与读写循环都不保存完整输入数组。

最终静默批次的第 0 次完整观测为 max/sum 41.111/197.169 ms，
同批五份参考的最小值为 41.342/215.076 ms。该批还进行了重复诊断，
docs/io.md 保留其中位数；本页阶段表统一使用真实首轮，口径不混用。

## 尝试过程与取舍

先以旧库与五份 OJ 提交作比较，测试短整数、完整八/十六位块、长整数尾部和输出格式的不同路径。中间也比较局部游标、位数界、分块大小及各种分支选择；最终保留成员游标，避免为微小收益增加接口和状态。read_pair 主要服务四到七位无符号输入，本题仍使用十九位单值读取。结果分块为 2048 项，随后又与 512/8192 等大小复查；没有把对高斯分布有效的单一路径强制用于所有均匀范围。
