# Integer Input Checksum

累加 N 个整数，输出和模 2^64。用 `u64` 累加，溢出本身就是取模；
负数先转成 `u64`，避免有符号加法溢出。L、R 用 `i128` 读取，因为输入允许完整的 i64 或 u64 范围。

- `scalar.cxx`：逐字符解析，作为简单基线。
- `generic.cxx`：调用 `Reader::read<T>()`，不提供位数提示。
- `bounded.cxx`：根据 L、R 选择最大十进制位数，再调用 `read<T, Digits>()`。
  分派只在循环前执行一次，不假定数据均匀，也不读取测例名。
- `main.cxx`：在范围分派的基础上，4～7 位无符号整数使用 `read_pair` 成对解析，
  其他范围保留单值读取。奇数个输入的最后一个数单独处理。

不保存数组，只输出一个校验和，使主要开销落在读取上。
测试包含常见均匀范围、负数、完整 64 位范围，以及页边界和十进制进位边界。
数据规模统计见 [io.md](../../../docs/io.md#输入范围与校验和题)。

## 尝试过程与取舍

这道自建题来自对原有题目常见数值范围的统计，重点测读取吞吐，只输出模 2^64 的校验和。先保留逐字符 scalar，再比较无提示 generic 与按 L/R 分派的 bounded。对四到七位无符号输入加入成对读取形成 main；其他范围继续单值解析。每个均匀范围单独代表常见输入，因此除汇总外，本页还保存定稿的逐范围表。少数范围仍有取舍，未强制宣称每个测例都更快；scalar、generic、bounded 都作为可运行的经典或通用对照保留。
