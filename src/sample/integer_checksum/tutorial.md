# Integer Input Checksum

累加 N 个整数，输出和模 2^64。用 `u64` 累加，溢出本身就是取模；
负数先转成 `u64`，避免有符号加法溢出。L、R 用 `i128` 读取，因为输入允许完整的 i64 或 u64 范围。

- `scalar.cxx`：逐字符解析，作为简单基线。
- `main.cxx`：调用 `Reader::read<T>()`，不提供位数提示。
- `bounded.cxx`：根据 L、R 选择最大十进制位数，再调用 `read<T, Digits>()`。
  分派只在循环前执行一次，不假定数据均匀，也不读取测例名。

不保存数组，只输出一个校验和，使主要开销落在读取上。
测试包含常见均匀范围、负数、完整 64 位范围，以及页边界和十进制进位边界。
数据规模统计见 [io.md](../../../docs/io.md#输入范围与校验和题)。
