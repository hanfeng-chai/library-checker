# 距离区间加与单点取值

`main.cxx` 使用 centroid_sum.h 的 Dual 模式。距离区间更新沿重心路径分配到
距离直方图，单点查询累加对应位置；小树用字节距离矩阵，链和星形树用直接路径。
初始权值与增量都在 [-1e9,1e9]，读入采用有符号十位提示，累计值保存在 i64。

46 个正式测例通过 GCC/Clang，独立带符号 BFS 对照通过 ASan/UBSan。
最终生产产物的 Lenovo 单次 max/sum 为 263.627/2586.965 ms，
同批五份参考的最小值分别为 276.008/3037.616 ms。

## 尝试过程与取舍

从点加、距离区间和的转置操作开始，实现距离区间加与单点取值。依次测试少分支重心的稀疏表、底部微块、链/星形直接处理和短距离数组。短数组对查询有利，但加法多的用例未必更快，因而将 Dual 的阈值设为 32，并按真实 ±1e9 范围选择十位读取。最终连续生成、散写每点路径记录，替代链式追寻，max 和 sum 才都取得明确余量。
