# 动态树子树加与子树和

主解使用 offline_forest_sum.h。已知操作序列后，将子树操作转为临时断开
给定父边后的连通块操作，处理完再连接。边权取负的删除时刻，从而保证每次
删除当前最大权边；anti-monopoly tree 维护阈值连通块和，差分偏移维护整块加。
每事件摊还 O(log N)，空间 O(N+Q)。这依赖离线信息，不能直接替代在线动态树。

## 尝试过程

先实现在线 Euler Tour Tree：每点一个带权标记，每边两个有向零权标记，
指定子树对应两条有向边标记之间的环形区间。splay 维护点数、和、加法标记。
初版每次通过旋转整条环形序列暴露区间；后改成只 splay 两个边界，查询或修改
一段中间区间，或两段外侧区间，减少操作，但速度仍明显落后。

接着实现在线 Link-cut Tree。加法标记改为相对父亲的差分偏移，旋转时只修正
旋转点、父亲和中间子树的偏移，不逐层下传整个子树的加法。对已有父边的查询
只做一次 access 和一次相邻点 splay。这个方案大幅快于 Euler Tour Tree，
仍没有超过最快离线参考。

最终采用离线方案。预先确定边的删除时刻，省去在线维护路径聚合的工作；
事件存为紧凑数组，不保存函数对象。整块加版本保留差分偏移，单点加的姊妹题
通过模板去掉不需要的标记。经典在线算法保留在 naive.cxx，使用 link_cut_subtree.h；它不需要预先知道后续删边时刻。

## 正确性

三个算法均通过 GCC/Clang 的正式测例。另用独立 BFS 对照随机正负权、重复断接
边、两个方向的子树加和查询，并检查十万点长链；通过 ASan/UBSan。
Euler Tour Tree 还检查边标记复用，离线算法检查临时断边查询后的重新连接。
