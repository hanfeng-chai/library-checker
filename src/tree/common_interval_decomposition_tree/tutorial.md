# 公共区间分解树

`main.cxx` 使用 interval_decomposition.h。逆排列的静态 RMQ 判断候选左边界
是否已被更早出现的数破坏，栈在线合并公共区间。相同方向的线性节点延长，
其他情况形成新的线性或 prime 节点。最后 BFS 输出，使父亲编号小于儿子。
分解过程线性，RMQ 的分块稀疏表占 O(n+(n/16)log(n/16)) 时间和空间。

## 尝试过程

最初维护 `max(P[l..r])-min(P[l..r])-(r-l)`：两个单调栈负责最大、最小值的变化，
区间加、最小值线段树寻找值为零的公共区间。算法正确，但每个元素要做多次
区间更新，成为主要开销。

先把未处理位置初始化为零，利用它们尚未被访问的性质，去掉每次的单点激活。
接着尝试直接找全局最左最小点，代替前缀最小值查询；这一步没有带来进一步收益。
再把初值设为下标 l，维护 `max-min+l`，全局最小值恰为当前右端点，因而还能
去掉一次前缀减一。虽然明显加快，仍不足以接近参考提交。

最终参考 Nachia 的方法，对逆排列做静态 RMQ。若候选值域中某个数的出现位置
早于候选左边界，这个候选以后也不可能成为公共区间，可以永久出栈。
值域长度等于下标区间长度时合并已有块。这一步省去了动态区间更新。

## 正确性

各候选通过 GCC/Clang 的正式测例检查。最终实现还独立枚举所有 n≤7 排列及
随机 n≤20 排列的公共区间，按强区间定义判断节点集合、孩子顺序、linear 标记，
并从原排列重算每个节点的值域边界，通过 ASan/UBSan。
