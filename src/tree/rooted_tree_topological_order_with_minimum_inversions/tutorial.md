`main.cxx` 使用 tree_order.h。每个连续块维护 C、D 总和，优先取 C/D 最大的非根块，
与其当前父块相接。交换两个无约束相邻块的代价比较为 D_A·C_B 与 D_B·C_A，
因此高比例块应尽量靠前；祖先约束通过合并父块处理。

选择的是全局最高比例，合并只会提高父块比例，所以索引堆更新父块时只需上浮。
每个活动块仅有一条堆记录，不产生旧版本。父块通过路径压缩寻找，next/tail
链表恢复排列，新增交叉成本直接累加 D_parent·C_child。
零权块规定为最小优先级，避免 0/0 破坏比较器；比较全部使用整数交叉乘积。

30 个官方测例通过 GCC/Clang；穷举小树的全部合法拓扑排列，含零权和比例相等，
验证最优代价与输出顺序，ASan/UBSan 通过。

## 尝试过程与取舍

按块内两类计数的比例贪心合并，并用 DSU 记录被吸收的父块。初版优先队列留下过期版本；随后改成带位置索引的堆，利用父块优先级变化方向只做必要调整，省去旧版本。小规模枚举全部合法拓扑序核对最优值，再进行完整比较。
