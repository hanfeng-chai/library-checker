# convolution_integer

`convolution_integer(a,b)` 返回非负整数卷积的 u64 系数。
输入每项小于 998244353，每个真实输出系数必须小于
`998244353*1004535809`；默认变换长度不超过 2^24。

较短输入不超过 16 项时直接计算，其余分别在两个素数下卷积，再作 CRT 还原。
AVX2 先重建偶数/奇数位置的 u64，随后交错写回。所有运算精确，不依赖浮点舍入。

大整数乘法把十进制拆为 10^4 进制、二进制拆为 13 位，题目范围内的
系数上界约 5e13，远小于两个模数的乘积；再进位回原来的存储基数。
GCC/Clang 通过大整数官方测例和 Python 乘法对照；独立朴素卷积还检验了
接近 1e18 的系数与素数 6700417 的组合。
