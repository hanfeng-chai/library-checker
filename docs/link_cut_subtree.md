# link_cut_subtree

`LinkCutSubtree<T=i64>(values)` 在线维护动态森林的子树加与子树和。
新对象可用 build_tree(graph,root) 初始化；link/cut 作用于有效边，add(v,x)
做点加。side_add(v,p,x)、side_sum(v,p) 作用于删去已有边 (v,p) 后含 v 的一侧。

每节点保存相对父亲的加法偏移、虚子树贡献、总点数和相对的总和。旋转时，
把父亲偏移加到提升的点，将旧偏移从下沉的点扣除，并补偿中间子树。
因此不需要为整棵子树逐层传播加法。反转仍只处理辅助树的方向。

已有父边的子树操作用一次 access 和相邻点 splay，根据相邻点是虚孩子还是
路径父亲，分别操作整树的补集或暴露的子树。时间摊还 O(log n)，空间 O(n)，
支持负数，约定 T 足以容纳中间和。与离线主解不同，它可逐条接收操作。
正式测例、独立带符号 BFS 对照和长链经 GCC/Clang、ASan/UBSan 验证。
