# polynomial_factorization

`polynomial_factorize(f,p,seed)` 分解首一多项式，运行时素数满足 `2<=p<2^30`，
默认非零随机种子。返回 `PolynomialFactors`，前 n 个条目各含普通模系数和重数，
因子互异、首一、不可约，顺序任意。常数 1 返回空列表。本实现面向小次数。

先作无平方因子分解；导数为零或剩下特征倍数重根时，提取 p 次根递归处理。
随后按不可约因子次数分组，再以随机迹或范数分裂同次数因子。
奇特征使用 Montgomery 模运算，特征 2 特化为位运算。

每个无平方部分只预计算一次 Frobenius 映射 a→a^p。
按输出系数排列矩阵，将后续调用转成连续点积；子因子整除原多项式，
所以同一矩阵也可在递归拆分后继续使用，再对当前因子取余。
八个乘积在 u64 中累加后统一约减，避免每个乘积单独约减。

67 个官方测例通过 GCC/Clang；194 组独立标量 Rabin 不可约性检验、
因子互异检查和乘积还原通过，ASan/UBSan 通过。Lenovo 每例一次，
max/sum 为 **28.800/261.444 ms**，五份对照最小值为 564.193/3513.869 ms。
证据在 `bench/poly-factor-power-20260930/round1/`。
