# partition_queue

`PartitionQueue(std::move(values))` 保存 i32 多重集合，支持 push、pop_min/max、
min/max、size；读取或删除极值要求非空。内部变换不影响元素的多重性。

按值域有序保存未排序的桶，只在取某一端极值且该桶超过 32 个显式元素时划分。
随机三数中位数选枢轴，AVX2 比较与压缩排列把元素分到两侧；小桶用 SIMD
同时归约极值及其下标。重复值可作为“键+次数”隐式保存，后续插入其他键也无需展开整段。

桶使用可增长的环形数组，初始 64 个槽；空集合保留最后一个桶的容量。
分桶思路可参考仓库的 nandhagk 提交；此实现使用 Buffer/Array，不依赖 libstdc++。
性能依赖划分效果，最坏情况不承诺严格对数操作时间。
需要任意平凡值类型与自定义比较器时，可用 [minmax_heap](minmax_heap.md)。

GCC/Clang 官方测例、独立朴素对照及 ASan/UBSan 通过；
额外验证了隐式重复段、i32 极值、环形数组扩容与有序排空。
