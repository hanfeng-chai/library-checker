# coverage

`CoverageTree(coordinates)` 用递增 u32 端点建立覆盖长度树。
`add(l,r,1)` 加入端点下标区间，`add(l,r,-1)` 撤销之前加入的同一区间；
`covered()` 返回并长度，空区间无影响。总跨度必须能用 u32 表示。

八叉树每个缓存行保存八个孩子的覆盖次数、下方未覆盖长度。
次数从零变正或从正变零时，可见长度才发生变化；AVX2 同时更新八个孩子。
边界上的局部变化逐层传播，已有完整覆盖时停止传播长度变化，但保留下方状态。
这样撤销覆盖后仍能恢复正确的子区间并长度。

增删 O(log n)，空间 O(n)。GCC/Clang 官方、匹配区间随机增删及 sanitizer 通过。
