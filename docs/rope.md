# rope

`Rope<P=0,B=512>(values,extra_capacity=0)` 保存 u32 序列，支持 insert(i,x)、
erase(i)、reverse(l,r)、sum(l,r)。P=0 返回 u64 和；指定奇数模数 P<2^30 时，
还支持 apply(l,r,{a,b})，所有输入值与系数使用规范余数。区间半开，空和为零。
B 是至少 16 的 8 倍数，默认 512；当前长度须适合 u32，整数和不溢出。

只有叶子保存数据块，内部节点保存长度、和、左右边界块大小与懒标记。
节点与块分池存放，空槽循环复用。树允许孩子高度差不超过 4；叶子除整体两端
外至少装 B/8 个数。concat 先查缓存的边界大小，只有不足时才访问边界并就地修复。

反转在两端的最低公共祖先处分开，同时下降两条路径；交换边界块外侧的片段，
再翻转整块区间。重建复用已记录路径和空出的内部节点，不反复从根 split/merge。
不合适的块长度回退到切分、拼接；所有边界修复都维护高度与装载量不变量。

叶子的反向标记决定物理下标，不必先把整块倒过来。区间内反转保留仿射标记；
删除直接扣掉被删除值在当前标记下的贡献；插入只物化必要的仿射标记。
转移边界片段时保留物理方向，只搬动必要部分，并只扫描较短一侧求局部和。

和使用普通余数、仿射标记使用 Montgomery 编码。AVX2 一次映射八个值；
求和先把 u32 拓宽到 u64，两个独立累加器并行累积。查询携带祖先标记和方向，
保持只读。已分配空间按历史最大长度计为 O(N_peak+B)，预留容量另计。树操作的额外
边界扫描为 O(B)，高度为 O(log(N/B+1))；整个序列反转为 O(1)。

GCC/Clang 全部官方测例及 ASan/UBSan 通过。小块随机对照另检查三种模数、
空序列、零斜率、池扩容/回收、全部物化值、高度差、块大小和缓存边界。
