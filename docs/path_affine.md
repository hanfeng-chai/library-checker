# path_affine

`PathAffineTree<P>(values)` 是保存仿射函数的紧凑二叉线段树，共约 2n 个节点。
`set(i,f)` 修改函数；`apply(l,r,x)` 按下标递增顺序应用 [l,r) 中的函数，
`apply<true>` 按相反顺序应用。输入函数系数、x 为规范余数，允许空区间和零乘数。
P 是小于 2^30 的奇数，不要求为素数。

每节点只存共享的斜率积和两个方向的截距，共 12 字节。斜率用 Montgomery
表示，截距保持普通余数。查询直接把覆盖节点作用于 x，反向一侧先暂存编号，
不为查询构造额外的复合函数。构造 O(n)，更新和查询 O(log n)，空间 O(n)。
