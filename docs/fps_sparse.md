# fps_sparse

输入是按 degree 递增的 `SparseTerm{degree, coefficient}` 数组，只存非零项，
输出为普通余数的 `Buffer<u32>`。默认模 998244353；P 须为奇素数，
涉及逐项除法的接口还要求 `8 | P-1`、输出长度 n<P。

- `fps_inv_sparse(terms,n)`：首项为非零常数。
- `fps_exp_sparse(terms,n)`：常数项为零，不在输入中。
- `fps_log_sparse(terms,n)`：首项为 `(0,1)`。
- `fps_pow_sparse(terms,n,k)`：非负 u64 指数，允许零级数，`0^0=1`。
- `fps_sqrt_sparse(terms,n)`：返回 optional；首项次数为奇数或首项系数无平方根时无解。

求逆使用向前代入，指数使用 `g'=f'g`，对数先解 `f*(x log(f)')=xf'`。
只从非零结果传播贡献，随机大间隔的输入往往比逐项扫描全部 K 个系数省很多工作。
最坏时间 O(nK)，空间 O(n+K)。

幂和平方根共用 `f*g'=k*f'*g` 的递推，先剥离前导 x 次幂。
指数与前导次数的乘积用 u128 判断，避免大指数溢出；平方根选较小的首项根，
不受条件约束的高项补零。整数逆元由 `fps.h` 的八条并行阶乘链计算。

Lenovo 独立空闲、不绑核，全部测例各测一次（2026-09-30），单位 ms：

| 题目 | main max | main sum | 对照最小 max | 对照最小 sum |
| --- | ---: | ---: | ---: | ---: |
| 稀疏逆 | 34.967 | 191.881 | 44.657 | 378.279 |
| 稀疏指数 | 64.838 | 377.917 | 77.458 | 817.878 |
| 稀疏对数 | 45.769 | 311.452 | 72.504 | 847.091 |
| 稀疏幂 | 70.248 | 516.151 | 94.659 | 1208.955 |
| 稀疏平方根 | 75.196 | 386.527 | 135.404 | 733.648 |

以上五题均胜过下载的五份提交。幂/平方根在非零项不超过 16、最大相对次数不超过 64
时维护递推系数的逐步差，先累加 u64 点积再统一取模；其余情况保留零贡献跳过。
这使稀疏幂 max 从约 222 ms 降至 70 ms。平方根相对初版 max 降低，sum 略增，
仍明显胜过五份对照。官方测例通过 GCC/Clang，朴素递推、乘积、恒等式对照及 sanitizer 通过。
原始结果在 `bench/fps-log-20260930/round1/`、`bench/fps-sparse-20260930/round1/`
和 `bench/fps-dense-20260930/round1/selected/`。
