# radix_ntt

`RadixNTT<P>(capacity)` 提供完整、位逆序的有限域频谱，接口为
`forward(span)`、`inverse(span)`；普通余数输入输出，逆变换包含长度归一化。
长度必须为二次幂、不超过 capacity 且整除 P-1，缓冲区至少 32 字节对齐。

大层复用 convolution 的 radix-4 部分变换，末三层在 AVX2 向量内完成。
选用与部分变换一致的二次幂单位根；逆变换抵消部分变换自带的 Montgomery
尺度和末端八点变换的尺度。长度小于 64 时使用普通 NTT。
完整频谱适合缓存块卷积的逐点乘加；单次卷积仍可使用八项多项式叶子，
不必强行完成这三层。

已对 998244353、17、97、193、469762049、754974721、167772161 的
合法二次幂长度进行频谱比较和正逆还原，GCC/Clang 与 ASan/UBSan 通过。
