# convolution_gf64

`convolution_gf64(std::move(a), std::move(b))` 计算 GF(2^64) 系数的普通卷积，
消费两个 Buffer，输入输出都是 `gf64.h` 的普通多项式基表示。

使用加法 FFT：先转换到 x²+x 的奇偶部分，再递归求值并做蝶形。
原有 Anonymous、Rohan_Kapri 提交提供了算法参考。本实现直接使用普通域乘法，
用 x^61 的 Artin–Schreier 链构造固定 Cantor 基，去掉随机找基、归一化和运行期求逆。
链末尾是 1，下一项是 0，编译期检查该性质。

短边不超过 32 时直接计算；恰好多一个系数会让变换翻倍时，先去掉最高项，
卷积后再补贡献。时间 O(N log² N)，额外空间 O(N)，要求支持 PCLMUL。

51 个官方测例通过 GCC/Clang；域乘法及 288 项朴素卷积对照、ASan/UBSan 通过。
