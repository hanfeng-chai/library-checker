# kd_affine

`AffineKDTree<P,B=64>(xs,ys,values,initially_active)` 预登记全部点，最前 initially_active
个点生效，其余等待激活。set(id,value) 激活或覆盖；apply(l,d,r,u,{a,b}) 更新矩形内
已激活点；sum(l,d,r,u) 查询活动点权和。矩形半开，支持重复坐标与零权重。

内部节点与点数据分开，叶子保存至多 B 个点，用 AVX2 同时筛选、变换八点。
整段和为普通余数，懒标记为 Montgomery 编码；边界更新先合并旧、新映射，
一次扫描即可物化叶子。只读查询携带祖先变换，避免写节点。

默认交替中位数切分。若一维基数极低且与另一维明显失衡，先聚合低基数维的
相同坐标，再切另一维；仍保持中位数的点数平衡，不依赖原始坐标的数值跨度。
包围盒按无符号顺序编码，用四路 SIMD 判断相交和包含。

激活或覆盖前推完路径上的旧标记，过去的更新不会影响未来点。
P 为小于 2^30 的奇数，点数<2^31；值与系数为规范余数。
GCC/Clang 官方、未来激活/覆盖/重复坐标/完整 u32/零斜率对照及 sanitizer 通过。
