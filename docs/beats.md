# beats

`SegmentBeats(values)` 支持 chmin(l,r,x)、chmax(l,r,x)、add(l,r,x)、sum(l,r)，
区间均半开；空区间和为零。数值与所有中间运算须适合 i64，真实极值严格位于
(-2^60,2^60)。节点保存实际元素数，补齐到二次幂的空叶子不参与聚合。

每段保存和、最大/次大值及最大值个数、最小/次小值及最小值个数。
若取 min 只影响最大值组，则直接调整和与极值；取 max 同理。否则下降处理。
等值区间改变极值时保留不变的计数及第二极值，并清掉可丢弃的旧加法标记。

迭代更新用端点末尾零位找出真正需要下传的路径，共同祖先只访问一次；
底部六层节点提前预取。查询携带祖先加法、上下界，只读节点；等值区间直接
用与查询相交的长度求和。预取不读取未来数据，也不改变执行顺序。

空间 O(N)，单次更新可能访问 O(N) 个节点；效率依赖 Beats 对极值组的跳过。
GCC/Clang 官方、朴素数组对照与 sanitizer 通过，含空区间、非二次幂、极值重合
和连续大幅加法后截断的情况。
