# fps_2d

`fps_inv_2d<P>(input,rows,columns)` 返回二元级数的逆，模 `x^rows,y^columns`。
输入、输出均为按 x 行、y 列存储的普通模系数，常数项非零。

先让较短维度作为行方向，从首行的一元逆开始逐次倍增 x 精度。
每行补至不少于两倍列数的二次幂，以一元 NTT 做二维乘积；
每步裁去超出 y 精度的项，避免进位污染下一行。
五次部分 NTT 完成一轮 Newton 更新，单行/单列退化为一元求逆。
变换长度须符合模数的根容量。

28 个官方测例通过 GCC/Clang，朴素二维乘积恒等式及 ASan/UBSan 通过。
Lenovo 单次静默 max/sum 为 **160.481/2250.536 ms**，
五份对照最小值为 358.499/6235.658 ms。
证据在 `bench/poly-newton-20260930/round1/`。
