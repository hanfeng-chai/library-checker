# tree_isomorphism

`rooted_classes(parent,hash=ChildrenHash{})` 要求 parent[0]=0 且 parent[v]<v，返回
类型总数 count 和每个根子树的 color。两个编号相同当且仅当根子树同构；允许空树。

逆序处理顶点：叶子为类型零，单孩子类型直接用数组登记；分叉点才排序孩子类型
并形成规范键。已用完的 CSR 游标复用为单孩子类型表，哈希表按分叉点数分配。
哈希表每槽保存 32 位指纹和代表顶点，命中时比较完整孩子序列，哈希碰撞不影响正确性。
子序列保存在连续的 CSR 区间中，无需为每个点单独分配容器。

空间 O(n)，排序使用整数基数排序与小数组插入排序；哈希探测时间为期望界。
独立括号字符串规范形、刻意令所有哈希相同的对照及 GCC/Clang、sanitizer 通过。
