# mode

`StaticRangeMode(values,queries=0)` 支持 query(l,r)，返回任一众数及出现次数。
要求 0≤l<r≤n、n<2^31，值为完整 u32。queries 是预期查询数提示，零表示未知。

前 1024 种不同值用小哈希表直接编号；超过后转稳定基数排序。
随后按实际值域与频率选择表示：

- 全相同或全不同时直接回答；仅两种值时使用一个标量前缀计数。
- 不同值不超过 1024 时，存块前缀计数，AVX2 同时比较八个频率，再补齐边界。
- 最高总频率 F≤128 时，保存每个左端点下 k 个相同元素的最早结束位置，
  二分得到最大可行 k；预处理 O(nF)，查询 O(log F)。
- 其他情况预处理完整块区间的众数，再检查边界出现位置；预处理 O(n²/B)，
  查询 O(B)，B 根据查询量提示选择。

所有策略均为精确算法，返回哪个并列众数没有保证。GCC/Clang 官方、完整 u32
高位/并列/块界/频次 128 与 129 切换/不同查询量的独立对照及 sanitizer 通过。
