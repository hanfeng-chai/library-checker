# affine_tree

`AffineTree<P>(values)` 消费普通系数的 Affine Buffer，支持 `set(i,f)` 和
`apply(l,r,x)`，函数按下标递增顺序应用。输入 x、系数须为规范余数。
P 为小于 2^30 的奇数，允许零斜率，空区间返回 x。

紧凑 2n 二叉树把叶子反向排列，查询按位枚举完整子区间，直接将其函数作用
于 x，省去构造第二个复合函数。内部斜率使用 Montgomery 编码，截距保持普通
余数，混合乘法直接得到普通截距或查询值，最终输出再规范化。

构造 O(n)，修改/查询 O(log n)，空间 O(n)。GCC/Clang、空数组/非二次幂/
随机仿射链朴素对照及 sanitizer 通过。双系数 SIMD 合并实测更慢，未采用。
