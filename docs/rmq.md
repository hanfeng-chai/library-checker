# rmq

`RMQ(std::move(values))` 建立静态区间最小值结构，`min(l,r)` 查询非空 [l,r)。
数组按 32 项分块。每个位置保存块内单调栈的位掩码，块内查询截去左端之前的
候选后取最低位；跨块查询合并两端的前缀/后缀最小值与整块 sparse table。

预处理和空间 O(n+(n/32)log(n/32))，查询 O(1)。T 为支持比较的整数类型。


`u32` 特化使用 16 项分块，AVX2 构造前缀/后缀最小值并扫描块内查询。
宏观 sparse table 额外保存一行单位元，跨相邻块时无需判断中间区间是否为空。
主解按 128 个查询一批读取、预取和输出。GCC/Clang 官方与独立对照及 sanitizer 通过。
