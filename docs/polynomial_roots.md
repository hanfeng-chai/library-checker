# polynomial_roots

`polynomial_roots<P>(std::move(f),seed)` 返回非零多项式在 F_P 中的所有不同根，
顺序任意。P 为满足底层 NTT 条件的奇素数，默认 998244353；随机种子应非零。

先移除零根，用 `gcd(f,x^(P-1)-1)` 去掉重根和非线性因子，
再按 `(x+c)^((P-1)/2)` 在各根处的值为 ±1 随机二分。
线性、二次因子直接求根；模幂复用固定除数的频谱，GCD 使用半 GCD。
随机化影响用时，输出始终由精确的有限域运算确定。

官方测例通过 GCC/Clang；小素数逐点枚举、已知根构造及模幂对照、
ASan/UBSan 通过。Lenovo 首轮 max/sum 为 **129.177/1663.732 ms**，
五份对照最小值为 516.346/6337.979 ms，均达标。证据在
`bench/poly-factor-power-20260930/round1/`，每例仅测一次。
