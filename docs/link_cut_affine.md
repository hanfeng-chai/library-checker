# link_cut_affine

`LinkCutAffine<P=998244353>(values)` 维护森林上顶点的仿射函数。P 为小于 2^30
的奇数，允许零乘数；输入系数和查询参数均为规范余数。build_tree、link、cut
约定与 link_cut_sum 相同，set(v,f) 覆盖函数，apply(u,v,x) 按 u 到 v 的路径顺序
应用函数，返回规范余数。

每个 splay 节点缓存共享的斜率积和正反两个方向的截距。斜率使用 Montgomery
编码、截距保持普通余数；操作摊还 O(log n)，空间 O(n)。反转标记在旋转前局部
下传，节点缓存自己是左孩子、右孩子还是辅助树根，省掉反复访问祖父的判断。
access 拉起目标点时直接旋转接入新父亲，减少一次完整 splay 和重复聚合；
单点改函数只需 splay，不改变首选路径。全部遍历迭代完成。

内部 splay 不刷新最终根的聚合值，调用者必须 pull 或继续 access 的重接流程，
再读取该根的聚合值。对外接口已完成这些步骤。
23 个官方测例通过 GCC/Clang；动态断接边、正反路径、零乘数、奇合数模数与
十万点长链的独立对照通过 ASan/UBSan。
