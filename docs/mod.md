# mod

`Mod<P>` 提供标量及 AVX2 模加减、Montgomery 乘法，另有标量普通乘法和幂。
要求 P 是小于 2^30 的奇数，输入和结果均归约到 `[0, P)`。

`mul(a,b)` 返回 `ab mod P`；`mont(a,b)` 返回 `ab/R mod P`，其中 R=2^32。
`mont(x, r2)` 将普通余数转成 Montgomery 表示。两种表示不能随意混用；
卷积接口在内部处理转换，对调用者只暴露普通余数。

`Barrett(p)` 用于运行期给定的 `1 < p < 2^32`。构造时计算一次倒数，
`mul(a,b)` 用高位乘积替代除法；`pow(a,n)` 用二进制幂。
乘数可取整个 u32 范围，结果为普通余数，不涉及 Montgomery 表示。
