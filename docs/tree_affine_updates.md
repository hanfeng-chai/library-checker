# tree_affine_updates

`TreeAffineUpdates<P=998244353, Reroot=false>(values, edges, root=0)` 维护固定树形。
每条 AffineEdge 保存 u、v、a、b，两个方向均使用 ax+b。P 是小于 2^30 的奇数，
输入均为规范余数；允许零乘数和奇合数模数，不依赖除法。

`set_vertex(v,x)` 改点权，`set_edge(i,a,b)` 按输入边编号改函数。
`root_sum()` 返回所有点权沿路径送到初始根后的总和；Reroot=true 时，
`sum(r)` 支持任意查询根，查询不改变初始根。空树的 root_sum 为零。

每条重链构造按轻子树大小加权的 Cartesian 二叉树。顶点吸收其父边，缓存
轻子树的和与点数；链段表示 `(S,C) -> (a*S+b*C+c, C+count)`。
修改沿二叉树向上传播，跨轻边时只把旧、新贡献之差加到父亲，不维护动态旋转。
加权布局使总传播长度为 O(log n)。初始化 O(n)，空间 O(n)。

任意根版本额外缓存反向的 b、c，斜率积和点数共用。查询收集重链上方、下方
的聚合，将不在目标路径上的部分归入轻子树，再向上一条重链继续，O(log n)。
点数不是模数值，路径上的常数项按实际点数累加。

两题各 26 个正式测例通过 GCC/Clang；独立 DFS 校验随机点/边修改、任意初始根
和查询根、零乘数、模 15/17/998244353，以及十万点长链，并通过 ASan/UBSan。
