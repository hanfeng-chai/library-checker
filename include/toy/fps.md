# fps

系数为普通模余数，默认 P=998244353；缺少的输入系数视为零。
底层部分 NTT 要求 P 是小于 2^30 且满足 `8 | P-1` 的素数，变换长度符合根容量。
涉及积分或按次数除法的接口还要求精度 n<P。

- `fps_inv<P>(f,n)`：返回 1/f 的前 n 项，n>0 时 f[0] 非零。
- `fps_div<P>(a,b,n)`：返回 a/b 的前 n 项，b[0] 非零。
- `fps_log<P>(f,n)`：返回 log(f)，要求 f[0]=1。
- `fps_exp<P>(f,n)`：返回 exp(f)，要求 f[0]=0。
- `fps_pow<P>(f,n,k)`：返回 f^k，k 为 u64，约定 0^0=1。
- `fps_sqrt<P>(f,n)`：返回 optional；前导次数为奇数或首项无平方根时无解。

求逆先递推 32 项，再倍增精度。已知 G 的前 m 项，只计算 fG-1 的高 m 项，
再乘 G 并取负，补出逆的新高段。循环卷积回卷只污染低半段，每轮五次部分 NTT，
复用 G 的频谱；次数不超过 3 的输入直接递推。时间 O(n log n)，工作区 O(n)。

除法把结果分成约 16 块，缓存除数和已求商块的完整频谱。
每块求一次残差，再用首块的逆得到商块；频点的正负号分离相邻乘积的高低段。
对数采用求逆、卷积后积分的路线。

指数同时维护 exp(f) 和其倒数的正确前缀，用
`(f-log(g))'=(f'g-g')/g` 计算新高段。普通更新做 11 次部分变换，
最后一轮无需维护倒数，只做 8 次。平方根类似，只补出 `(f-g²)/(2g)` 的新高段。

整数幂先剥离前导零和常数因子，再由 `f*Dg=k*(Df)*g` 直接分块求幂，
其中 D=x*d/dx。首块递归，缓存 f、Df、g 的频谱，用首块逆和整数逆元解下一块。
块间高位通过 `x^B=±1` 合入，复用 [radix_ntt](radix_ntt.md) 的完整频谱。
残差、导数和按次数除法使用 SIMD；无需位移时直接返回结果缓冲。
次数偏移用原整数指数和 u128 判断，不能提前将指数取模 P。

`inverse_numbers<P>(n)` 返回 1..n 的逆元，下标 0 留零，要求 n<P。
按下标模 8 分成八条阶乘链，批量求逆，避免逐项整数除法。
第二个模板参数为 true 时保留 Montgomery 表示，供积分等批量模乘使用。

GCC/Clang 官方测例、截断乘积恒等式、朴素递推对照及 ASan/UBSan 通过。
当前各题的 max/sum、五份对照和原始证据统一见 [评测审计](../../tools/measurement_audit.md)。
