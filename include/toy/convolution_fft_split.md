# convolution_fft_split

`convolution_fft_split<P, Packed>(a,b)` 用浮点 FFT 计算整数卷积；输入为无符号
span，返回 Buffer。`P=0` 表示保留低 64 位，否则要求 `1<P<2^30`、输入小于 P。
本轮只在模 2^64、模 10^9+7 两题保留这种对照；模 998244353 的题解直接使用 NTT。

系数分为 13 位小块，低位块采用有符号表示，最高块保留剩余商；补齐长度超过
2^20 时使用 10 位块。先变换各块，再按块下标之和累加乘积，逆变换并舍入，
最后乘回相应的二进制权重。模 2^64 时只计算仍影响低 64 位的组合。
短边不超过 16 时直接相乘，不用 NTT 回退冒充 FFT。

- `Packed=false`：每个系数占一个复数，虚部为零，是较直接的分块 FFT 基线。
- `Packed=true`：偶数位置放实部、奇数位置放虚部，变换长度减半。
  若打包多项式为 E+iO、F+iG，则乘积为 EF-OG+i(EG+OF)，加上 `(1+x)OG`
  就得到原卷积的偶数、奇数部分；代码利用共轭频点恢复 O、G。

两者共用 `fft_convolution.h` 的 AVX2 radix-4 内核，没有手写汇编指令。
`fft_naive.cxx` 是新补的经典对照，不是虚构的历史 FFT 版本；历史 NTT/CRT
代码保存在各题的 `naive.cxx`。

这是通过舍入恢复整数的算法。正确性需要每个待恢复整数的误差小于 0.5，
不能仅凭 double 能表示该数量级就认为任意规模都安全。当前正式用途为两题
补齐长度不超过 2^20 的输入，验证包含官方数据、位数边界和独立整数乘法对照。
13/10 位分支和两种布局也有小规模精确对照。扩大范围需重新核实精度。

所有保留版本与同题 NTT/CRT 使用相同的最新数组读取和输出模板。
结果见 [模 2^64](../../src/convolution/convolution_mod_2_64/bench.txt) 与
[模 10^9+7](../../src/convolution/convolution_mod_1000000007/bench.txt)。
