# interval_decomposition

`IntervalDecomposition(permutation)` 构建公共区间分解树，输入必须是 [0,n) 的排列。
root 为根节点下标，零表示空树；nodes[0] 是哨兵。节点保存下标、值域的半开区间，
linear 标记，以及 first/last/next 链接的有序孩子列表。

先对逆排列构造静态 RMQ。扫描右端点，用栈保存候选左边界及值域：若值域内
某个数已出现在左边界之前，该候选以后也不可能形成公共区间，直接删除；否则
值域长度等于下标区间长度时得到公共区间，并合并已有节点。相同方向的线性
节点直接延长，多于两个已有块的合并形成 prime 节点。节点池连续存储。
算法参考仓库中的 Nachia 提交，复用 toy/rmq.h，省去动态区间加数据结构。

栈处理与节点合并为 O(n)。RMQ 使用 16 元素块，预处理时间及空间为
O(n+(n/16)log(n/16))，查询 O(1)。输出可用迭代遍历避免深递归。
全部 30 个官方测例通过 GCC/Clang。独立枚举公共区间、检查强区间定义和线性
节点定义，覆盖所有 n≤7 排列与随机 n≤20 排列，并通过 ASan/UBSan。
