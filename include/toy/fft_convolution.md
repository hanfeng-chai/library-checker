# fft_convolution

`convolution_fft<P>(a,b)` 接收普通余数 span，返回 Buffer。P 是小于 2^30 的奇素数。
这是浮点 FFT 路径，靠舍入恢复整数；当前限制补齐后的长度不超过 2^20。
短边不超过 16 或长度更大时改用 `convolution_crt`，并受其长度、系数界限制。
需要精确整数算法时可直接选 CRT。这里的浮点范围经过测试，不是任意输入的形式化舍入保证。

选取最小 d，使 -d 在模 P 下有平方根 r；把系数写成 `re+im*r`，
用零表示的二维格将坐标缩小，再嵌入复数 `re+i*sqrt(d)*im`。
这样一次模卷积只需两次正 FFT 和一次逆 FFT。格嵌入方法参考仓库
Rohan_Kapri、adamant 的 cp-algo 提交，坐标舍入使用固定下标扰动，保持运行可复现。

内核使用 AVX2 radix-4，四个相邻系数同处一个向量，叶子直接乘模 `x^4-w` 的
小多项式。子树在缓存中完成；根表索引用移位和递增，避免内层整数除法。
仅本模块的大缓冲区按 2 MiB 对齐并请求 Linux 大页，普通 Buffer 的分配策略不变。
