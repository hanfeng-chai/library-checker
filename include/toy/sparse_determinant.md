# sparse_determinant

`sparse_determinant<P>(n,entries)` 接收位置互异的 `MatrixEntry{row,column,value}`，
缺省项为零，值在 `[0,P)`。空矩阵行列式为 1。

先检测零行、零列及带权置换矩阵。一般情况做精确高斯消元：优先选非零项少
的行，再选列，减少填充；行列位图只枚举可能受影响的非零项。行、列交换的
符号分别计入结果，行更新共用固定乘数的 Shoup 商近似。

数值使用连续稠密工作区，位图和度数保持稀疏遍历；最坏 O(n³) 时间、O(n²)
空间。没有 Wiedemann 投影的概率误判，适合本题 n <= 3000、初始非零项不多的矩阵。
