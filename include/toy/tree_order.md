# tree_order

`minimum_tree_order(parent,c,d)` 要求 parent[0]=0、parent[v]<v，c、d 非负且各自
总和适合 u32。返回祖先在前的排列，以及 sum_{j<i} c[p_i]·d[p_j] 的最小值；
交叉乘积和总成本须适合 u64，支持空树与零权重。

将每个顶点视为块。若两个块可交换，先放 c/d 更大的块不会更差；用最大堆
选择非根块并与其尚未合并的父块连接，累加 D_parent·C_child 的新增交叉成本。
零权块单独约定为最小优先级，避免 0/0 破坏比较器的传递性。

父块由路径压缩寻找，链接数组保持块内顺序。索引堆每个活动块只有一条记录；
选出的子块比例全局最大，所以父块合并后只需上浮，无需保留旧版本。空间 O(n)。穷举所有合法拓扑排列的独立对照覆盖零权与
比例相等，GCC/Clang 和 sanitizer 通过。
