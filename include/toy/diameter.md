# diameter

`TreeDiameter(n)` 依次 add_edge(u,v,w)，再 solve(root=0) 返回 length 与 path。
输入须为一棵树，边权为非负 u32，总路径长度不超出 u64。空树返回空路径；
零权树允许返回单点路径。solve 消耗内部状态，只调用一次。

每个点保存度数、相邻编号的 xor 与相邻边权的 xor。剥到叶子时，xor 就给出
唯一剩余邻居和边权；把最长向下路径传给父亲，同时更新经过父亲的最长路径。
固定根防止其提前删除，父指针用于恢复两个端点到汇合处的路径。无需邻接表。
时间与空间 O(n)。Floyd–Warshall 全点对距离与返回路径独立检查覆盖空树、单点、
任意根、零边权和不同形状，GCC/Clang 与 sanitizer 通过。
