# 网络单纯形

`NetworkSimplex` 与 MinCostFlow 的输入、结果接口相同。人工根连接所有供需点，构造初始可行基树；足够大的惩罚使原问题可行时人工流全部归零。一次换基沿基本环推流，并替换饱和树边。

每块八条残量边，选取最负的检验数，避免始终选第一条负边所导致的微小改进。连续 n 次零流量换基后使用 Bland 规则，直到目标函数再次严格下降。对偶势按树路径惰性求值；换基时只让被翻转路径上的缓存失效，已确认不变的祖先势继续复用。费用目标使用 i128。

不超过 128 点时，用 u128 保存基树每个子树的顶点集；一次换基对被切下的整个分量平移对偶势，避免定价时递归查询势。更大的图仍使用路径缓存。
