# wildcard_match

`wildcard_match(s,t)` 返回每个对齐位置的 `'0'` / `'1'`。字符是小写字母或 `*`，
任一侧的 `*` 都能匹配任何字符；要求 `0 < |t| <= |s|`。

先尝试精确过滤：不相等的非通配字符对很少时直接枚举；否则为文本的每种字符
建立兼容位置位图。每个非通配模式字符将位图平移并与候选取交，候选清空的
64 位块立即移除。AVX2 比较建立位图，模式位置以互质步长遍历，优先覆盖不同
区域。位图操作总量设为输入长度的常数倍，预算不足回退 NTT，
所以极端重复输入不会使过滤退化成无界的二次算法。

NTT 计算每个对齐的 `sum((a-b)^2 * mask_a * mask_b)`，拆成三个卷积。
六次正变换后先累加乘积，只做一次逆变换。字母编码 1..26，通配为 0；要求
`625*|t| < 998244353`，则结果为零当且仅当匹配，不存在哈希碰撞或浮点误差。
最坏时间 O(n log n)，空间 O(n)。`wildcard_match<false>` 跳过过滤，保留纯 NTT
实现作为经典对照。
