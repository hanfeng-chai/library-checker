# big_division

`BigDivision<Hex>::divmod(a,b,q,r)` 计算带符号整数商与余数，商向零截断，
余数与被除数同号。除数非零；q、r 必须彼此独立，且不能与 a、b 重合。
连续计算复用一个 `BigDivision`，保留 FFT 根表与工作区。

小除数或很短的商用 Knuth D；十六进制的 128/64 位试商直接使用 x86 DIV，
调用处保证高半字小于除数。形如单个非零肢乘基数幂的除数直接逐肢除法。

大数先用递归 Newton 求倒数下界。循环卷积恢复有符号误差项，截去对修正值影响
不足 1 的低位尾部，以保守方向舍入，再做修正乘法。长商按块处理，复用倒数和除数频谱；
按 FFT 长度边界估算工作量来选块宽。短商只保留除数的必要高位并向上取整。
最终用原除数校正商和余数。

依赖 [big_integer](big_integer.md) 与 [fft_integer](fft_integer.md)。使用后者的
浮点快速路径，精度范围与拆位约束同该文档；不依赖 GMP 或 libstdc++。
循环乘积缩短变换的思路也可参考仓库中的 Anonymous 大整数除法提交。

验证包括 GCC/Clang 全部官方测例、Python 商余数对照、带符号边界、
两种进制各 324 组倒数对照，以及大测例 ASan/UBSan。最终性能见评测审计。
