# convolution

`convolution.h` 提供普通余数数组的模卷积，`buffer.h` 管理 64 字节对齐的存储。
Buffer 初始内容未初始化；`resize` 扩展部分补零。传入卷积的两个 Buffer 会被消费，
返回结果持有自己的存储，无需 libstdc++。

```cpp
Buffer<u32> a(n, capacity), b(m, capacity);
// 填入 [0, P) 的系数；提前预留 FFT 容量可以避免重新分配。
auto c = convolution<998244353>(std::move(a), std::move(b));
```

短边不超过 16 时，倒序直接计算，复用较长输入的存储；每项至多累加 16 个乘积，
在模数小于 2^30 时不会溢出 u64。较大输入使用 radix-4 DIF/DIT 和四个并行的
8 点叶子，内核改编自仓库的 Anonymous 提交 #393372。已去掉原有 I/O、计时器、
平台分配封装和未使用的根表；SIMD 的范围与数据布局在代码旁说明。

叶子计算模 `x^8-w` 的小多项式乘积，不需要继续展开成标量频点。
因此长度 N 的变换只需要 N/8 阶单位根，要求 P 是满足 `8 | P-1` 的素数、
`P < 2^30`，并且 `N/8` 不超过 `P-1` 的最大二次幂因子。
卷积对外接收、返回的都是普通余数，内部 Montgomery 因子在逆变换中消除。

`convolution_cyclic<P>(a,b)` 消费两个等长、长度为二次幂的 Buffer，计算模 x^N-1
的循环卷积。它复用相同内核，避免先计算两倍长度的普通卷积再折叠。

整次卷积的新版缓存融合接口见 [`convolution_fast.h`](convolution_fast.md)。
本头文件保留可独立正变换、乘法、逆变换的接口，供复用频谱的算法使用。
下面是旧主解的历史记录；当前数值以各题 bench.txt 为准。
