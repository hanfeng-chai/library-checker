# suffix_order

后缀数组内部的精确证书，调用者无需直接使用。

`periodic_order` 从前 128 字节推测不超过 64 的周期，再比较完整输入验证。
验证成功后排序各余数类和短尾巴，同余类内按后缀长度递增输出；任何字符串都
先经过完整验证，不根据输入文件名或生成器选择答案。

`prefix_order` 把尽可能多的字符和后缀长度压入 64 位键。先按高 20 位做两趟
radix，再排序至多 64 项的小桶。字符范围为 26 字母时可用 BMI2 压缩前八字节，
再追加第九字节。若桶太大或相等键尚不能确定顺序，就回退 SA-IS。
抽样只用于避免无效尝试；最终所有键都检查，抽样不影响正确性。

`factor_names` 针对长度不超过八个符号、不同种类不超过 128 的完整 LMS 子串，
直接生成名字，省去第一次诱导排序。键的末尾补全 1：当一个 LMS 子串是真前缀
时，它的终点属于 S 型，应排在更长子串之后；原串结束则补唯一零哨兵。
字典比较完整键，探测过多或约束不满足即回退普通命名。
