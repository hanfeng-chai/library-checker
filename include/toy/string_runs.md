# string_runs

`string_runs(s)` 返回所有 `{period,left,right}`，表示 `[left,right)` 的极大
周期区间，长度至少为两倍最小周期；按三元组排序、去重。要求 n < 2^21，
三个下标能无损压入一个 63 位整数。

两种相反的字母序各做一次 Lyndon 单调栈，找到候选根，再用向前 LCE 和反串 LCE
扩展到极大区间。`AdaptiveLCE` 先直接比较字符，每个方向的累计预算
为 64n；预算不足就建立后缀数组、Kasai LCP 和 RMQ。这样随机串无需建索引，长重复串仍有确定的
工作量上界，全程不使用哈希。

`SuffixLCE` 可单独用于静态最长公共前缀查询。扫描时直接存储压缩键，按实际
位数做五或六趟 radix 排序，最后解码三元组。
runs 数量 r=O(n)，其余部分使用线性数量的栈操作和 LCE 查询。
