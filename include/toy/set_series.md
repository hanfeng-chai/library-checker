# set_series

集合幂级数存为长度 2^n 的普通模系数数组，乘法模所有 x_i²。
`set_exp(f)` 要求 f[0]=0；`set_log(f)` 要求 f[0]=1。
`set_compose(polynomial,f)` 允许任意 f[0]。
`set_power_projection(f,weights,count)` 返回前 count 个幂与权重的内积。
默认 P=998244353，要求 n<P，投影的 count<P，底层卷积须支持所需变换长度。

逐个加入变量，把输入写成 A+xB，利用 x²=0：

- exp(A+xB)=exp(A)+x B exp(A)。
- log(A+xB)=log(A)+x B/A，直接使用子集除法。
- f^(r)(A+xB)=f^(r)(A)+x B f^(r+1)(A)。

复合从 f 在常数项处的前 n 阶导数出发，每轮减少需要维护的导数个数。
最高阶导数为常数时直接缩放，其余乘法复用 subset_convolution。
投影反向执行同一线性过程；转置子集乘法可通过补集反转、子集卷积、再反转实现。
常数项非零时，用一次普通卷积将导数权重转换成幂的权重。
这些构造的子集运算总计 O(n² 2^n)，保留的导数/权重数组合计 O(2^n)。
子集卷积工作区另需 O(n 2^n)。

GCC/Clang 通过全部官方测例：子集卷积 11、exp 13、log 12、复合 18、投影 30。
小规模朴素子集乘积、指数展开、log/exp 还原、复合和加权幂通过，ASan/UBSan 通过。
