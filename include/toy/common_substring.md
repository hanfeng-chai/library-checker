# common_substring

`common_substring(s,t)` 求两个小写字母串的最长公共子串，返回 `{a,b,c,d}`，
满足 `s[a:b] == t[c:d]`。并列答案任取一个，空答案返回全零。

先检查完整包含、字母集合不交、单一字母等可直接确认的情形。普通输入把 q 个
字符压成一个 32 位键，建立保留所有出现位置的字典，匹配键后双向延伸。
已有长度 L 的答案时，只需每隔 `max(1,L-q+2)` 个位置采样：任何更长的公共子串
都含有一个完整采样键。

键是字符的无损编码；哈希只负责选桶，每次都比较完整键。抽样仅决定是否尝试
这条路径，探测次数和延伸总量都有线性预算；无法完成证明就回退后缀自动机。
不存在把随机碰撞当成答案的情况，固定字母表下最坏时间、空间均 O(n+m)。
