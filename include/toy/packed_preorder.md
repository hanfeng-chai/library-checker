# packed_preorder

`TreePreorder(n)`、`add_edge(u,v)`、`build(root=0)` 把一棵静态树重编号为 DFS 序。
position[原编号] 与 vertex[DFS 编号] 互逆；parent、depth 按 DFS 编号存放，
parent[0]=0，其他点满足 parent[v]<v。子树在 DFS 序上连续。

构造时每点 16 字节记录度数、邻居异或、子树大小和深度。剥叶得到父亲与
子树大小，逆序处理得到父亲在前的顺序；从子树末端向前分配孩子区间。
完成后释放构造节点，只保留四组输出。时间、空间均为 O(n)，全部迭代完成。

用于静态查询和动态树初始布局：后者重编号一次即可，随后 cut/link 改变拓扑
时仍使用同一个顶点映射。不同初始根、路径/星形/随机树及动态映射对照通过验证。
