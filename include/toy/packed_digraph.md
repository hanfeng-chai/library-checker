# 复用边记录的有向图遍历

`PackedDigraph(n,m)` 逐条 `add(u,v)`，随后调用 `cycle()`、`components()` 或 `component_ids()`。每次遍历都会破坏内部记录，不能在同一对象上连续调用两个查询。

要求 n、m 小于 2^21；一条记录用三个 21 位字段保存链接、顶点或 DFS 状态。未访问顶点缓存第一条出边，DFS 返回记录和 SCC 活动链复用已经消费的边槽。`cycle()` 返回按环方向排列的原边号，空结果表示无环。`components()` 的分组为拓扑顺序；`component_ids()` 只保证同组同号，编号为逆拓扑顺序。时间、空间均 O(n+m)。

紧凑记录与首条出边缓存参考仓库中的 `learningstud` SCC／有向环提交；保留了独立于输入输出的接口。
