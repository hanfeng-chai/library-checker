# xor_set

`XorSet<Bits>(reserve)` 维护 [0,2^Bits) 内无重复整数，9≤Bits≤32。
insert/erase 返回集合是否改变；contains/size 查询成员与大小；min_xor(x)
返回与 x 异或后的最小值，要求集合非空。reserve 是预计位图叶数量，可自动增长。

每 512 个键共用一个目录槽；单元素直接编码在槽中，第二个不同元素才分配
64 字节位图。空叶通过内嵌空闲链回收。上层 Bitmap 标记非空块，按异或距离
逐层选择前缀，再选择叶中的字和位。每次选择优先保留与查询高位相同的非空半边。

目录空间 4·2^(Bits−9) 字节，另有约目录大小 1/32 的占用索引和按需位图叶。
Bits=30 时目录为 8 MiB。适合值域已知、访问密集的整数集合；稀疏完整 u32
值域可用 patricia.h，节省初始化空间但随机访存较多。GCC/Clang 官方、完整 u32
随机对照、删除复用及 sanitizer 通过。
