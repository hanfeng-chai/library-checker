# ntt_asm

[`convolution_fast.h`](convolution_fast.md) 的内部 AVX2 实现，不是独立卷积接口。
模板参数为模数 P，要求与调用者相同；面向本项目 x86-64-v3、Linux、GCC/Clang。

保留 Aiyiyi 提交中实际使用的三种上层蝶形及一个融合叶子循环，沿用内核名与指令
顺序，方便和参考核对。根与 Shoup 商的偏移、叶子窗口布局均由 ProductNTT 准备。
前向范围小于 4P，逆向小于 2P；输入数组需对齐并留出末尾可读余量。

约 1000 行主要是固定寄存器和指令调度。纯 C++ 对照未达到同样速度；删除更多
汇编须重新检查产物及完整测例，不能只依赖源码操作数看起来等价。

`TOY_NTT_ASM=0` 时不包含本头文件，所有蝶形和叶子乘积都由 C++ intrinsics
实现。默认汇编版和该对照共用同一个上层算法，避免维护两份完整 NTT。
