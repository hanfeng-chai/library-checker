# tree_distance_histogram

`tree_distance_histogram(graph)` 返回树中无序不同顶点对的距离频数，长度为 n，
下标零为零。当前验证范围 n≤200000，图须为无向树。

对每个点分重心，从重心单点的直方图开始，按支大小递增加入各支。每次只计算
新支与之前部分之间的卷积，直接累计无序点对；避免分别平方再抵消同支贡献。
短直方图直接相乘，较大者复用 IntegerFFT 的计划。计数为 u64，不取模。

时间 O(n log² n)，辅助空间 O(n)。FFT 使用舍入恢复整数，全部官方测例通过
GCC/Clang。BFS 全点对、4097 点长链、120001 点扫帚树的闭式频数（含超过
32 位的系数）等独立对照另通过 ASan/UBSan。
