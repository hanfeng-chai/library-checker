# rectangle_add_point

`RectangleAddPointGet<T=i64>(updates_hint,queries_hint)` 按时间记录 add(l,d,r,u,w)
和 query(x,y)。query 返回答案编号；最后 solve() 返回同顺序的答案 Buffer。
矩形半开，空矩形自动略过，支持负权。操作数须小于 2^30，中间加减与累计结果不超出 T 的范围。

每个查询只需要它发生前的矩形。把这个时间前缀分解为若干 lowbit 块，各块内部
扫描 x，用 y 差分 Fenwick 做矩形加、单点查询。更新端点按块渐进合并，查询在
父时间块中已按坐标排序，分发到子块后仍有序，不必反复排序。

首次查询之前，只需保留一个完整大块，因此直接基数排序这个块，省掉其内部的
逐层合并。Fenwick 的两个相反更新到达共同祖先后相互抵消，提前停止写入。
最后一次查询之后的更新无需处理。

空间 O(N+Q)，保守时间 O((N+Q) log²(N+1))。返回值是查询时的历史答案，
不是把所有矩形先加入后的静态结果。GCC/Clang 官方、负权/空矩形/重复边界/
零时刻/末尾更新的朴素历史对照及 sanitizer 通过。
