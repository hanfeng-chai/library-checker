# fft_integer

IntegerFFT 缓存根表与两块工作区。输入是非负小系数（不超过 16383），
快速路径的补零长度至多 2^20；结果为舍入后的 u64 整数系数。
普通更长乘积退回双模精确卷积。Fixed 的 FFT 长度应满足上述快速路径范围。

偶数系数放实部，奇数系数放虚部，复变换长度减半。设 y=x²，
(Ea+iOa)(Eb+iOb) 的实部少了 (y+1)OaOb，通过配对共轭频点补回。
底层沿用 fft_convolution 的 radix-4、四项多项式叶子；整数路径以 256 个
C4 向量为一个缓存子树，通用模卷积继续使用原有的 1024 个。
Fixed 缓存一侧频谱，支持固定长度线性或循环卷积；平方只需一次正变换。

本接口是浮点快速路径，不是模运算恒等式意义上的精确 CRT。
已在题目最大范围、最大系数、常数/交替/稀疏/随机及官方 FFT killer 下，
用双模整数卷积逐系数核对；GCC/Clang 与 sanitizer 检查通过。
范围以外应使用 convolution_integer 或调整拆位，不应外推精度结论。
