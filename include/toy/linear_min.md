# linear_min

`LinearAddMin(values)` 支持 add(l,r,a,b)，给区间中的第 i 项增加 a·i+b，
minimum(l,r) 查询最小值。区间半开；空区间返回 infinity=2e18。
数值、懒标记及中间算术须适合 i64，真实值须严格小于 infinity。

Kinetic 线段树保存每段当前最小值、获胜下标及向正负方向改变斜率的安全距离。
距离受两个孩子的安全距离和两个候选直线的交点共同约束。落在安全距离内时，
获胜下标不变，直接调整聚合与懒标记；越界时下降、更新孩子并重算距离。
更新沿迭代边界路径下传与回收；只读查询携带祖先变换，不写节点。

空间 O(n)，查询 O(log n)。一次更新耗时取决于失效节点数，最坏 O(n)；
交替改变全局斜率可能反复使许多节点失效，不宣称任意操作序列的对数摊还界。
旧 linear_range.hpp/bridge_hull_tree.cpp 保留凸包桥方案供参考。

GCC/Clang 官方、非二次幂/空区间/正负更新/交替斜率朴素对照及 sanitizer 通过。
本题验证器允许 b=±100、c=±10000000，读取上界按包含端点处理。
