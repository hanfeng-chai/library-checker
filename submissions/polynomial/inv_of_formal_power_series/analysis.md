# Inverse of Formal Power Series：从系数方程到高半段求逆

给定长度 `N` 的数组 `f`，求另一个数组 `g`，使两个多项式相乘后
前 `N` 项为 `[1,0,…,0]`。本题 `1≤N≤500000`，模数
`p=998244353`，保证 `f[0]≠0`。
最快一批仍围绕 Newton 修正，但有的用循环与负循环卷积恢复高段，
有的一轮补三倍的新系数，并非所有源码都只是换了一套同样的 NTT。

## 1. 求的是整个级数的倒数

题目要求

$$
f(x)g(x)\equiv1\pmod{x^N}.
$$

这里 `mod x^N` 意味着只保留下标 `0,…,N−1`。例如
`f=1+x`、`N=4` 时，答案是 `g=1−x+x²−x³`，因为乘积为
`1−x⁴`，丢掉四次及以上项后就是 1。

这不是对每个 `f_i` 分别求模逆，也不是求复合逆 `f(g(x))=x`。
数组表示普通多项式系数，不带阶乘缩放。模意义下的 `−1` 输出为
`p−1`；分数 `a/b` 表示 `a·b^{-1} mod p`。

### 1.1 常数项为何必须非零

乘积常数项为 `f_0g_0=1`。如果 `f_0=0` 就不可能成立；本题保证
它非零，所以在质数模域中有唯一的 `g_0=f_0^{-1}`。
比较其余系数：

$$
g_k=-f_0^{-1}\sum_{i=1}^{k}f_i g_{k-i}.
$$

右边只依赖之前的答案，因此每项都唯一确定。
例如 `f=2+x` 时，连续得到

```text
g0 = 1/2
g1 = -g0/2 = -1/4
g2 = -g1/2 = 1/8
g3 = -g2/2 = -1/16
```

`f` 可以在常数项后含任意多个零，不需要找前导零或平移；其常数项
已经由题目保证可逆。`N=1` 时只输出 `f_0^{-1}`。

### 1.2 朴素递推是可靠的短输入参照

```text
g[0] = inverse_integer(f[0])
for k = 1 .. N-1:
    g[k] = -g[0] * sum(f[i]*g[k-i], i=1..k)
```

总时间 `O(N²)`、空间 `O(N)`。求和结构是卷积，但 `g` 也是未知
数组，不能直接把未求出的完整 `g` 送进一次 NTT。快速方法需要
先维护一个正确前缀，再成批补全后续项。

## 2. Newton 更新为什么让正确前缀翻倍

假设 `G` 已经正确到 `m` 项，写 `fG=1−e`，其中 `e` 被 `x^m`
整除。取

$$
G_{new}=G(1+e)=G(2-fG).
$$

则 `fG_new=(1−e)(1+e)=1−e²`；`e²` 被 `x^{2m}` 整除，
所以新答案正确到 `2m` 项。这是精确的代数性质，不是实数迭代的
近似收敛。

例如 `f=1+x`，已有 `G=1−x mod x²`。误差 `e=x²`，于是
`G_new=(1−x)(1+x²)=1−x+x²−x³ mod x⁴`。

若长度 `t` 的乘法费用为 `M(t)=O(t log t)`，倍增长度的费用之和
`M(2)+M(4)+…` 为 `O(M(N))`。实现所需工作数组可以保持线性空间。

### 2.1 只计算高半段能少做什么

改写为 `fG=1+x^m E`，则

$$
G_{new}=G-x^m GE\pmod{x^{2m}}.
$$

旧低项不变，只需补高 `m` 项。常见内核如下：

```text
A = f 的前 2m 项
B = G，补零到 2m 项
Ahat = NTT(A); Bhat = NTT(B)
error = INTT(Ahat * Bhat)
清零 error 的低 m 项
correction = INTT(NTT(error) * Bhat)
新高半段 = -correction[m..2m)
```

这需要 3 次正变换、2 次逆变换，第二次乘法复用 `Bhat`。
长度 `2m` 的循环卷积会回卷，但 `A·B` 次数小于 `3m`，回卷只
落入低 `m` 项；它们马上被清零。下一次乘法也只读取不受回卷影响的
高半段。因此不需要为每个乘积都补到接近 `4m`。

这个安全性依赖于精度和次数边界。若从同一个短卷积中读取所有低项，
就不能继续使用上述理由。

## 3. 上游 `correct.cpp` 是快速算法，但表达式产生更多完整乘积

[题面](../../../upstream/polynomial/inv_of_formal_power_series/task.md)、
[约束配置](../../../upstream/polynomial/inv_of_formal_power_series/info.toml)
和[实际参考实现](../../../upstream/polynomial/inv_of_formal_power_series/sol/correct.cpp)
都在仓库中。`main` 读入数组后调用 `Poly::inv(n)`，再输出恰好 `N`
项。其迭代为：

```text
res = [1/f[0]]
for m = 1,2,4,...，直到 m>=N:
    res = (2*res - res*res*f.pre(2*m)).pre(2*m)
最后裁到 N 项
```

这是同一个 Newton 公式。乘法运算符先计算完整卷积再裁剪，
`res*res` 和随后乘 `f` 是两个独立调用；没有显式保留频域 `res`
供下一次乘法复用。

`multiply()` 在较短操作数长度不超过 8 时直接二次相乘，否则用
整数 NTT。普通 NTT 路径做两次正变换、一次逆变换，并为各次调用
构造工作数组。平方输入也没有在该接口专门省掉第二次正变换。
逐层变换有临时数组重排，模乘写作 64 位乘积 `%p`，输出使用
`scanf/printf`。常量 `%p` 可能被编译器化为乘法和移位，不宜直接
把源码中的每次 `%` 都称为一次硬件除法。

其总复杂度仍为 `O(N log N)`、空间 `O(N)`。公开快解主要减少
重复变换、无用系数和内存扫描，而不是把二次基线首次改成 NTT。

### 4.1 #400150：用两种回卷方式恢复同一个高段

实际入口为 `main→eez::fps998::inv_to→inv_to_impl`。
先用二次递推求至多 64 项；之后每轮调用 `step_3half`。
其工作区 `a,b` 一次预留并复用，最终只写要求的新前缀。

要理解这个不同于普通五变换内核的写法，令

$$
T=fG^2-G.
$$

`G` 长度为 `m`，`f` 截到 `2m`，则 `deg T<4m`，且 `T` 的低
`m` 项为零。分成四块就是
`T=0+x^mT_1+x^{2m}T_2+x^{3m}T_3`。
所求新高段为 `−T_1`。

代码分别求：

| 卷积环境 | 得到的块 |
|---|---|
| 模 `x^m−1`，普通循环卷积 | `C=T_1+T_2+T_3` |
| 模 `x^{2m}+1`，负循环卷积 | `D_0=−T_2`，`D_1=T_1−T_3` |

于是 `T_1=(C+D_0+D_1)/2`。这就是 `recover_high` 把三段相加、
乘 `1/2`、再取负的原因。相比算完整三次乘积，它只保留恢复目标
高段所需的两个余式。

`cubic_cyclic/cubic_negacyclic` 把乘 `G²` 与减 `G` 合在同一组
变换中。负循环通过单位根扭转使跨过 `2m` 的项变号；同类原理也见
[卷积教程](../convolution_mod/analysis.md)。本题模数为奇数，`1/2`
存在；次数上界和低块为零都是恢复公式的前提。

底层自适应保留 8 或 16 项的小块，在局部使用小块乘积或 Karatsuba，
结合 Montgomery 与 AVX2，避免把每个阶段都完全变换到底。
这属于变换调度和局部乘法的融合，并不是另一条求逆恒等式。
源码直接指定 `avx2,bmi,bmi2,lzcnt,popcnt` 等目标特性，没有为任意
旧 CPU 提供运行时派发保证。输入输出也采用专门的无检查快读写。

### 4.2 #261768：高半段 Newton，把负号并入逆变换

`solve()` 调用 `No_Poly::inv(g,f,n)`。`conv(o,h,t)` 完成第一次
乘法后保留了旧逆的变换 `h`；代码清掉 `o` 的低半段，再
`dif→dot→dit<nR>`，把需要的负号/尺度合入逆变换，最后复制新高段。
预先分配两段工作区，避免每个乘法都创建临时向量。

底层是 AVX2 的整数 NTT 和带尺度约定的模乘。主函数直接读普通
剩余值，最终用 `mul_s(g[i],out(1))` 补偿表示后输出；不能只看到
库里的 Montgomery 乘法，就把输入和所有中间数组都当作同一种编码。
库中的商、指数、平方根函数没有被本题调用。

### 4.3 #146019：实际调用的是 `Inv_10En`

`solve()` 将 `N−1` 传给 `poly::Inv_10En(F,N−1,G)`，因为这个接口
的参数表示最高下标，而不是长度。其循环实际处理 `n+1` 项。
一次 `Conv`、清低半段、复用旧逆频域值、第二次逆变换和取负，
对应第 2 节高半段算法。

同一源码还定义了使用不同回卷恢复的 `Inv_9En`，但本题入口没有
调用它。函数名中的 `9E/10E` 不宜直接视为 OJ 实测速度结论。
后端使用基 4 的 8 路向量蝶形、可复用的内存分配区和尺度修正，
输出的 `trans<-2>` 也是表示补偿。读写走 `mmap` 与查表缓冲。

小边界还需留意：`Inv_10En` 先执行 `bit_up(n)`，其中使用
`__builtin_clz(n)`；`N=1` 时传入最高下标 0，会触及 `clz(0)`
的未定义表达式。快照 AC 不构成这段代码在任意工具链下可移植的保证。

### 4.4 #382183：一轮把精度从 `m` 提到 `4m`

`main` 先把长度补到 8 的倍数、转进模表示，再调用
`AvxInfo::inv_9_33e_4th`。小规模不超过 16 项直接递推；大规模按
最终二次幂指数的奇偶，选 8 或 16 项种子，此后每轮 `t*=4`。

设 `e=fG−1` 从 `x^m` 开始，则

$$
(1+e)(1-e+e^2-e^3)=1-e^4.
$$

因此 `G_new=G(1−e+e²−e³) mod x^{4m}`。源码把 `e` 的三个新块
记成类似 `a0,a1,a2` 的切片，复用 `a0²` 和
`a0(2a1−low(a0²))` 来组成二阶、三阶误差，最后统一乘旧 `G`。
减少迭代轮数的同时增加了每轮局部乘法；不能由“四倍”推断运行时间
必然是二倍迭代的一半。

同一对象保存 NTT 根信息与 AVX2 向量模乘参数，工作内存对齐到
64 字节。代码直接使用向量指令，没有看到运行时 CPU 特性回退。
输出前批量转回普通剩余值，只打印原始 `N` 项。

### 4.5 #223105：固定算满 `2^19`，输入长度只控制读写

`main` 调用的是 `nt.inv_fast_fromvals(19,coef,buf)`，不是把
`ceil(log₂N)` 传进去。全局 `coef[1<<19]` 的未输入部分初始为 0，
因此低 `N` 项的逆仍正确，但短输入也支付求 524288 项的成本。

内核逐层保存旧低项，取 `fG` 的高半段移到低段并取负，乘旧逆后
再移回高段，最后恢复旧低项。参数 `all_vals` 在本题为默认空指针，
所以没有从调用方复用预先计算的最终输入变换。这个实际分支不能
仅凭函数名中的 `fromvals` 推断。

它使用 AVX2/Montgomery NTT、全局数组、映射输入和缓冲输出。
主路径的固定上界覆盖题目最大 `N=500000`；从不同输入大小比较
空间和时间时，应把固定容量 `U=2^19` 计入，而不能简单写成小输入
也只消耗 `O(N)` 的初始化与计算。

## 5. 条件、成本和验证

| 检查点 | 为什么必要 |
|---|---|
| `f_0≠0` | 常数项方程必须可解 |
| 最后一轮只保留 `N` 项 | 补齐二次幂不改变题目要求的长度 |
| 短卷积只读取安全高段 | 回卷会污染被舍弃的低项 |
| 模表示与 NTT 缩放配套 | 不能直接交换不同库的 `dif/dit` |
| SIMD 的对齐、尾块和 CPU 条件 | 数学公式正确不保证向量访存和指令可用 |
| 固定精度实现记录实际长度 | 不同 `N` 的耗时不能只按渐进公式解释 |

本页核对了五份源码的 SHA-256 与配置，并沿各自入口追踪实际内核。
本地对 `m=1,2,4,8,16` 共 40 组模随机输入验证四倍误差修正和
循环/负循环高段恢复，均与独立二次递推一致。另可统一检查
`fG mod x^N=1`，作为移植实现时的不变量。
没有新增候选源码编译、OJ 请求或性能测试。

若要测某项优化的收益，固定同一机器、后端、输入与输出，分别替换
高半段算法、四倍迭代或循环/负循环恢复；记录每种长度的变换次数、
工作区和运行时间分布。小输入覆盖 `1,8,16,64` 及其相邻值，大输入
覆盖二次幂前后和上界。快照的 25–32 ms 不能直接拆成某一个优化
贡献了几毫秒，也不能代表本题之外的通用求逆性能。
