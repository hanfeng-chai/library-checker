# 最长公共子串：从二维动态规划，到相邻后缀、自动机与精确过滤

题目要找两个字符串中最长的一段**连续且相同**的内容，并输出它在两串里的区间。高效路线可以排序所有后缀，也可以用一串建立自动机再扫描另一串；最快样本还会先验证容易确定答案的情况，必要时才建立完整后缀索引。

## 阅读导航

第 1～2 节给出手算与朴素动态规划；第 3～4 节推导上游的 SA/LCP 方法；第 5 节解释 SAM 扫描；第 6～8 节对应五份真实提交，特别说明种子过滤的精确性与回退；最后列出快照和验证条件。

可配合[后缀数组教程](../suffixarray/analysis.md)阅读 SA-IS 的完整诱导过程，以及[不同子串教程](../number_of_substrings/analysis.md)理解 SAM 状态与 clone。本文保留当前问题需要的基本推导，伪代码不冒充作者原实现。

## 1. 题意、区间与完整例子

[题面](../../../upstream/string/longest_common_substring/task.md)给小写串 S、T，二者长度都在 `1..500000`，见[配置](../../../upstream/string/longest_common_substring/info.toml)。输出 `a b c d`，表示

```text
S[a..b) == T[c..d)
```

且公共内容长度最大。半开区间不包含右端，所以 `b-a=d-c`。多个最优答案任取一个；没有共同字符时输出 `0 0 0 0`。

取

```text
S = a b a b a
    0 1 2 3 4
T = b a b c
    0 1 2 3
```

最长公共子串是 `bab`，区间为 `S[1..4)`、`T[0..3)`，输出 `1 4 0 3`。长度 4 不可能：S 的两段四字符串是 `abab,baba`，T 的唯一四字符串是 `babc`，均不同。

“连续”不能漏掉。例如 `abc` 与 `ac` 可以按子序列跳过 `b` 取得 `ac`，但最长公共**子串**只能是长度 1 的 `a` 或 `c`。

## 2. 朴素方法与动态规划

枚举两串起点，再向后比较，需要 `O(|S||T|min(|S|,|T|))` 的宽松最坏时间。可以把“在这两个位置同时结束的公共段”作为动态规划状态：

```text
dp[i+1][j+1] = S[i]==T[j] ? dp[i][j]+1 : 0
```

遇到不同字符必须清零，因为公共子串不能跳过它。答案取所有格子的最大值，记住两个结束位置后向前减长度即可。

主例的表（不展示全零边界行列）为：

| S 字符 / T 字符 | b | a | b | c |
| --- | ---: | ---: | ---: | ---: |
| a（0） | 0 | 1 | 0 | 0 |
| b（1） | 1 | 0 | 2 | 0 |
| a（2） | 0 | 2 | 0 | 0 |
| b（3） | 1 | 0 | 3 | 0 |
| a（4） | 0 | 2 | 0 | 0 |

最大格子为 3，结束位置为 S 的 4、T 的 3，因此返回 `[4-3,4)` 与 `[3-3,3)`。

滚动数组可以把空间降到 `O(min(|S|,|T|))`，但时间仍为两串长度乘积，最大有 `2.5×10^11` 个格子。本题需要共享更多比较结果。

## 3. 把两串放在一起排序后缀

拼接 `U=S+"#"+T`，其中 `#` 不在输入字母表中。每个原串里的子串都是某个后缀的前缀，所以最长公共子串等于来自两侧的某对后缀的最大 LCP。

### 3.1 为什么分隔符不可省

S 后缀如果匹配到自己的结束位置，下一字符是 `#`；T 的真实字符永远不是它，因此跨两串的 LCP 会停止，不会把 S 末尾与 T 开头拼出的虚假内容当答案。

排序实现还可能另加一个唯一最小哨兵 0。**中间分隔符与排序末尾哨兵是两种角色**，都不属于答案区间。分隔符只要与真实字母不同即可，不必一定比所有字母小。

### 3.2 完整排序主例

`U=ababa#babc`，S 起点为 `0..4`，分隔符位置 5，T 起点为 `6..9`。不含末尾空后缀的排序如下：

| SA 起点 | 后缀 | 所属 | 与前一后缀 LCP | 是否为跨两串的有效候选 |
| ---: | --- | --- | ---: | --- |
| 5 | `#babc` | 分隔符 | 0 | 否 |
| 4 | `a#babc` | S | 0 | 否 |
| 2 | `aba#babc` | S | 1 | 否，同属 S |
| 0 | `ababa#babc` | S | 3 | 否，同属 S |
| 7 | `abc` | T | 2 | 是，公共 `ab` |
| 3 | `ba#babc` | S | 0 | 是，但长度零 |
| 1 | `baba#babc` | S | 2 | 否，同属 S |
| 6 | `babc` | T | 3 | 是，公共 `bab` |
| 8 | `bc` | T | 1 | 否，同属 T |
| 9 | `c` | T | 0 | 否，同属 T |

起点 1 与 6 给长度 3。T 在拼接串里的起点要减 `|S|+1=6`，得到 `0`，所以恢复为 `1 4 0 3`。

### 3.3 为什么只检查相邻异色后缀

把来自 S 的后缀标成一种颜色，T 标另一种。所有以相同字符串 P 开头的后缀，在字典序中形成连续区间。

如果 P 在两串中都出现，这个区间里包含两种颜色，沿区间走一定能遇到一对相邻异色后缀。它们至少共享 P，因此最大公共子串必能在某对相邻异色后缀中找到。

这消除了枚举所有跨串起点对的需要：排序后只检查线性数量的邻居。相邻同色后缀的 LCP 可能很长，但它本身不能证明两个输入串都有这段内容。

## 4. 上游 `correct.cpp` 的实际流程

[上游源码](../../../upstream/string/longest_common_substring/sol/correct.cpp)执行：

```text
scanf 读 S、T，构造 U=S+"#"+T
sa_is(U)：排序含末尾唯一哨兵的全部后缀
SA(U,order)：建立逆排名和相邻 LCP
扫描相邻起点，只保留一侧在 S、一侧在 T 的候选
记录最大长度，并把 T 坐标减去 |S|+1
输出半开区间
```

SA-IS 将后缀分成 S/L 类型，选出 L 后接 S 的 LMS，桶诱导、命名 LMS 小块并递归排序缩小序列。LMS 不相邻使规模每层约减半，在小写字母表下为 `O(|S|+|T|)` 时间与空间。

LCP 不是每对从零扫描，而是按原位置 i 遍历，用上一次匹配长度减 1 作为下界继续比较；这就是 Kasai 的线性复用。实现保留完整 SA、逆排名和 LCP，随后再扫描找最大值。

题目对相同最大长度的答案没有固定挑选规则，上游只在 `ans<k` 时更新。它与其他正确提交输出不同区间可能只是选了不同最优位置；[checker](../../../upstream/string/longest_common_substring/checker.cpp)检查边界、等长、内容相同和最优长度。

## 5. SAM 路线：在另一串上维护当前最长可匹配后缀

SAM 把一串的子串按结束位置集合分组。状态记录最长长度、后缀链接和字符转移，整个结构只有线性个状态。不同子串计数教程给出了 `abb` 需要 clone 的完整例子。

建立 S 的 SAM 后，逐字符扫描 T，维护：

- `v`：当前匹配落在哪个状态。
- `matched`：T 当前前缀的最长后缀中，出现在 S 里的长度。

能沿字符边走就让长度加 1；没有边，则沿 suffix link 缩短候选，并把长度降到新状态的最长长度，直到可以继续或回根。

```text
教学伪代码
v=root，matched=best=0
for 每个 T[j]:
    while v!=root 且没有 T[j] 转移:
        v=link[v]
        matched=len[v]
    if 有转移:
        v=next[v][T[j]]
        matched++
    else:
        v=root，matched=0
    若 matched>best：记录状态代表位置与 j+1
```

### 5.1 状态最长长度不等于当前匹配长度

在 `S=ababa` 的 SAM 中，一些状态的最长串为 `ab`、`aba`、`abab`。用它扫描 `T=babc`：

| 已读 T 前缀 | 当前匹配串 | matched | 所在状态的最长串 |
| --- | --- | ---: | --- |
| `b` | `b` | 1 | `ab`，最长长度 2 |
| `ba` | `ba` | 2 | `aba`，最长长度 3 |
| `bab` | `bab` | 3 | `abab`，最长长度 4 |
| `babc` | 空 | 0 | `c` 不在 S 中，回根 |

同一个状态表示一段长度范围，所以必须同时保存 `matched`。若每次转移都把它设成 `len[v]`，第一步就会错误地认为单个 `b` 匹配了两个字符。

状态 `abab` 的一个代表结束位置为 4，当前长度 3，故 S 区间为 `[1,4)`；T 结束位置为 3，区间为 `[0,3)`。状态代表串即便更长，其对应后缀仍给出一个合法出现位置。

扫描时长度每读一个字符最多加 1，每次失败跳转严格缩短；总增加和总下降都受输入长度控制，固定字母表下扫描为线性。

## 6. #403347：先证明容易的答案，再用精确种子过滤，失败则 SA-IS

[源码](../../selected/longest_common_substring/403347.cpp)的 `main` 调用字节字符串版 `canard::longest_common_substring`，默认开启 `certificates` 与 `seed_filter`。不能只看到文件含 SA-IS 就说每组输入都排序，也不能把它归为随机哈希答案。

### 6.1 这些提前返回都能证明已达到全局最优

| 检查 | 为什么能直接返回 |
| --- | --- |
| 公共前缀长度等于较短串长度 | 已达到任何公共子串的上界 `min(N,M)` |
| 较短串是较长串的完整后缀 | 同样达到上界 |
| 两串字符最小/最大范围不相交 | 不可能有任何共同字符 |
| 至少一串全为同一个字符 | 只需在另一串找该字符最长连续段，并以短串长度为上限 |

这些检查完整核验相关字符。若只得到一个不够长的公共前缀，它成为已有答案的下界，不能直接认定最优。

### 6.2 “种子”是装得下的短字符串，不是有碰撞的答案摘要

`seeded_common_substring` 先把短串放前面。仅在其长度至少 256、至多 `2^21` 且非单字符字母表时尝试；本题最大短边低于后一阈值。

它选择固定长度 q，把每字符的连续编码占用若干位，要求总位数不超过 32，组成一个**无损的 32 位键**。固定 q 下，不同 q 字符串有不同完整键。

哈希只用于找存储桶；撞桶时比较完整键，短串中同键的所有出现位置都保留在链表中。随后对长串的某个 q 字符窗口，找到所有相同种子，直接比较真实字符向左右扩展，得到合法候选。

只保留同键的一个出现位置会漏答案：相同短片段在不同位置可能有不同的左右延伸。因此完整出现链是正确性所需，重复过多时则由预算触发回退。

### 6.3 为什么能跳过长串的一些种子位置

假设已知合法答案长度为 B，种子长 q，且 `B≥q`。任何更好的答案至少长 `B+1`，其中包含

```text
(B+1)-q+1 = B-q+2
```

个连续可选种子起点。按步长至多 `B-q+2` 检查长串，总能在任何更长公共段里碰到至少一个完整种子。

例如 B=3、q=2，要漏掉的改进至少长 4；四字符段有三个二字符窗口，步长 3 的检查必然覆盖其中一个。程序用 `j += best.length-q+2`（答案尚短时用步长 1），扩展匹配后还能增大步长。

扫描结束时，若已知答案仍短于 `q-1`，就不能排除长度小于 q 的更好答案，源码返回失败要求精确回退。它没有把“没发现 q 长种子”直接等同于没有公共子串。

### 6.4 抽样和工作预算如何保持正确性

抽样只决定是否值得尝试：短串 128 个样本的键重复过多就放弃。真正运行时保留全部位置、比较完整键，并设探测预算 `8(N+M)`、候选/扩展预算 `4(N+M)`，单次哈希探测链也有 64 的上限。

超预算返回 `nullopt`，不是返回当前最好但尚未证明最优的答案。随后会尝试一次按完整实际字母表压紧编码的版本，或回退 SA-IS；两次有限预算尝试加上保底仍为线性级工作。

紧编码对 `{'a','z'}` 这类 ASCII 范围大、实际字符少的输入有用：对两串统一映射，保持相等关系，减少每字符编码位数。它先完整扫描字符集合，不能各串独立压缩导致不同字母恰好获得相同数字。

### 6.5 SA-IS 保底只扩展必要的跨串相邻对

回退拼接编码使用中间分隔符 1、末尾哨兵 0，真实字符从 2 起。它建立后缀顺序后构造“起点→字典序后继”的表，释放排序工作存储，不建立完整逆排名与 LCP 结果数组。

扫描时仅对跨两串的相邻后缀，且剩余可匹配长度足以超过当前 best 时，继续比较真实字符。对于同串或无需扩展的相邻对，仍把已经知道的公共前缀**下界递减 1 后保留**；若每次遇到同串对都把下界清零，会丢失 Kasai 的摊还优势。

底层 SA 还包含完整验证的短周期、交替最小分隔符归约、LMS 小块命名等分流，见[不同子串计数教程](../number_of_substrings/analysis.md)。本题小写字母使字节编码足够，通用任意对象比较、相等类编码以及 16 位全字节回退不属于这个 main 的常规可达路径。

本文件面向 AVX2 与 Linux 普通文件输入，字符扩展有受边界限制的块比较。快照没有每测试分支轨迹，因此不能把 13 ms 只归给种子过滤或只归给 SA-IS。

## 7. #402204：较短串建 SAM，较长串扫描

[源码](../../selected/longest_common_substring/402204.cpp)先在必要时交换 S、T，使构建串较短，再执行 `suffix_automaton(std::move(s)).longest_common_substring(t)`；输出前把坐标交换回原顺序。

它使用第 5 节的状态/长度双变量。当前字符不在建串字母表时直接清零；否则逐级 suffix link 回退，更新最大值时保存状态代表结束位置与扫描串结束位置，最后减去 best 得到区间。

普通 SAM 按实际字母表使用 1/2/4 宽行、扁平稠密行或两个内联转移再升级到 26 路的布局；较短串建库减少状态、clone 和转移存储。它没有拼接串和分隔符，也没有后缀排序、rank 或 LCP 数组。

构建仍采用默认 `Count=true`，顺带维护不同子串数，虽然本题不读取它；不能把后缀数组题 `Count=false` 专用构建的节省套用到这里。`cin/cout` 经 blazingio 宏替换，源码面向 AVX2。快照内存约 50.1 MB，实际大小随较短串和字母表分派而变。

### #299418：选择大于所有输入字符的分隔符，关闭 RMQ

[源码](../../selected/longest_common_substring/299418.cpp)的 `Yorisou → LCS` 取 `E=max(两串字符)+1` 作为分隔符，构造 `SA<0>`，再检查跨串邻居。小写字母下 E 仍在字符类型可表示范围内且不与输入相同；它可以大于输入字母，正确性并不要求分隔符排最前。

`SA<0>` 仍然执行 SA-IS 和 `keis_lcp`；模板参数 0 只是关闭额外 RMQ 稀疏表，不是“不计算 LCP”。其工作区为动态向量，保留完整 SA、逆排名和 LCP。通用区间查询接口没有被 main 调用。

## 10. 误区、正确性检查与后续实验

| 易错点 | 应检查的条件 |
| --- | --- |
| 子串可以跳字 | 必须连续，DP 不等时置零 |
| 最大相邻 LCP 就是答案 | 必须来自两个不同输入串 |
| 拼接后直接输出位置 | T 坐标要减 `|S|+1`，交换输入还要交换回去 |
| 分隔符与末尾哨兵是一个概念 | 两者各有用途，均不得进入答案 |
| SAM 状态最长长度就是当前匹配长度 | 同状态含多个长度，必须维护 matched |
| 种子哈希相同就证明最终答案 | 本实现键无损，完整比较键并真实扩展，超预算回退 |
| 没找到 q 长种子就能返回零 | 还可能有小于 q 的公共段，需已有下界或精确回退 |
| 不同最优坐标就是错误 | checker 接受任意最大长度的有效区间 |

小规模用第 2 节 DP 验证最优长度，再检查输出两区间等长且内容相同。覆盖完全相同串、短串位于长串开头/末尾/内部、没有共同字符、单字符重复、短答案、长重复种子和需要交换两串的长度组合。

性能实验应记录哪种提前验证成功、q 与候选数、预算是否耗尽、是否回退 SA、SAM 状态/clone 数；分别计读入、预处理、主算法和输出。保持输入和 I/O 一致，才能解释各项节省。此处是实验设计，本轮没有新增 benchmark。

本轮核查实际调用链、五份完整哈希、主例 DP/拼接 SA/LCP、SAM 扫描映射、种子覆盖算式及本地链接，没有访问 OJ/API。排名、AC 和时间仍属于原快照；通用模板中未被调用的比较/编码/查询模块不计入本题热路径。
