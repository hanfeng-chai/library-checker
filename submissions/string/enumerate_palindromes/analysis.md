# 枚举回文：从中心扩展到 Manacher，以及快解省掉的分隔符和转换

这题不是只求整个字符串的最长回文，而是对每个可能的中心，输出在那里能扩到的最长回文长度。中心既可以落在字符上，也可以落在相邻字符之间。

## 阅读导航

第 1～2 节手算所有中心和朴素扩展；第 3 节解释镜像复用与线性证明；第 4 节对应上游的分隔符和跳段实现；第 5～6 节逐份比较双数组、虚拟中心和 I/O；最后是快照、边界与验证设计。

文中“半径”有几种约定，会明确区分。教学伪代码不是任何提交的逐行复制。

## 1. 题意与一组完整输出

[题面](../../../upstream/string/enumerate_palindromes/task.md)给小写串 `S`，长度上限为 [500000](../../../upstream/string/enumerate_palindromes/info.toml)。共有 `2n-1` 个中心：字符 0、间隙 0/1、字符 1、间隙 1/2……字符 n-1。

取 `S=abacabba`，下标与字符为：

```text
下标  0 1 2 3 4 5 6 7
字符  a b a c a b b a
```

| 输出位置 | 中心 | 最大回文 | 长度 |
| ---: | --- | --- | ---: |
| 0 | 字符 0 | `a` | 1 |
| 1 | 间隙 0/1 | 无 | 0 |
| 2 | 字符 1 | `aba`，区间 `[0,3)` | 3 |
| 3 | 间隙 1/2 | 无 | 0 |
| 4 | 字符 2 | `a` | 1 |
| 5 | 间隙 2/3 | 无 | 0 |
| 6 | 字符 3 | `bacab`，区间 `[1,6)` | 5 |
| 7 | 间隙 3/4 | 无 | 0 |
| 8 | 字符 4 | `a` | 1 |
| 9 | 间隙 4/5 | 无 | 0 |
| 10 | 字符 5 | `b` | 1 |
| 11 | 间隙 5/6 | `abba`，区间 `[4,8)` | 4 |
| 12 | 字符 6 | `b` | 1 |
| 13 | 间隙 6/7 | 无 | 0 |
| 14 | 字符 7 | `a` | 1 |

输出为

```text
1 0 3 0 1 0 5 0 1 0 1 4 1 0 1
```

每个字符本身都构成长度 1 的回文，所以偶数编号的输出一定是正奇数；字符间隙对应偶数长度，可能为 0。间隙 5/6 也有较短的 `bb`，但只输出同中心的最大长度 4，不输出回文个数。

## 2. 朴素法：以每个中心同时向两边扩展

字符中心从 `(left,right)=(i,i)` 开始，间隙中心从 `(i,i+1)` 开始。若两端字符相等就各向外走一步，直到不等或越界。

```text
教学伪代码
best = 0
while left>=0 且 right<n 且 S[left]==S[right]:
    best = right-left+1
    left--
    right++
```

每个中心最多扩 `O(n)` 次，共 `O(n)` 个中心，最坏 `O(n²)`。全 `a` 的串会反复验证许多相同对称区域，是不能仅看随机串表现的原因。

Manacher 保留目前到达最右侧的回文，用它的对称性复用已经求过的结果。

## 3. 镜像：右侧中心能借用左侧中心多少信息

先只讨论所有中心都在字符上的情况。令 `P[i]` 是**包含中心的半径**：匹配位置为 `i-(P[i]-1)..i+(P[i]-1)`，总长度 `2P[i]-1`。

保存一个已知回文闭区间 `[L,R]`，中心 `C=(L+R)/2`，要求 `R` 在已经处理的回文中最远。对当前中心 `i≤R`，它的镜像位置为

```text
mirror = L+R-i = 2C-i
```

因为整个 `[L,R]` 左右对称，镜像中心处的回文可以映射到 `i`，但只能保证留在已知大回文以内。

### 3.1 两种情况

- 若 `P[mirror] < R-i+1`，镜像小回文完全落在大回文内部，连两端下一字符不相等也可镜像过去，`P[i]` 精确等于它。
- 若 `P[mirror] ≥ R-i+1`，只知道当前回文至少到 `R`，不能知道 `R` 外面是什么。先取 `R-i+1`，再实际比较继续扩展。

所以标准初始化是

```text
P[i] = i>R ? 1 : min(P[L+R-i], R-i+1)
```

再比较 `S[i-P[i]]` 与 `S[i+P[i]]`。若伸得更远，更新 `[L,R]`。

### 3.2 为什么总扩展次数是线性的

在旧回文内部，如果镜像答案已经结束，最多再碰到一次失败；如果实际比较成功，就在推进新的最右边界。`R` 单调增加，总共最多走过字符串长度。每个中心最多有一次终止比较，因此所有中心合计 `O(n)`。

外层遍历中心、内层扩展并不必然形成平方时间；关键是已知区域由镜像复制，成功的新比较只推进边界。

## 4. 上游如何统一奇偶中心

[上游 `correct.cpp`](../../../upstream/string/enumerate_palindromes/sol/correct.cpp)把字符之间插入 `$`，末尾不保留分隔符。输入是小写字母，所以 `$` 不会与真实字符混淆。

例如

```text
原串：a b b a
新串：a $ b $ b $ a
下标：0 1 2 3 4 5 6
```

原串的字符中心与间隙中心，现在都是新串的字符位置，恰好对应题目的 `2n-1` 项。

### 4.1 完整计算 `abba` 的转换

上游原始 `res[i]` 采用第 3 节“包含中心的半径”约定：

| 新串位置 | 字符 | 原始半径 res | 原串回文长度 |
| ---: | --- | ---: | ---: |
| 0 | a | 1 | 1 |
| 1 | $ | 1 | 0 |
| 2 | b | 2 | 1 |
| 3 | $ | 4 | 4 |
| 4 | b | 2 | 1 |
| 5 | $ | 1 | 0 |
| 6 | a | 1 | 1 |

位置 3 扩过 `$`、`b`、`$`、`a`，半径为 4，对应原串长度 4。位置 2 的半径 2 包含左右分隔符，却只覆盖一个真实字符，因此不能把原始半径直接输出。

源码最后逐项转换：

```text
新串位置为偶数（原字符中心）：2*floor((res+1)/2)-1
新串位置为奇数（原间隙中心）：2*floor(res/2)
```

得到 `1 0 1 4 1 0 1`。整数除法取整与奇偶性都是公式的一部分。

### 4.2 上游不是逐中心的 l/r 写法，而是扩展后跳过整段

实际变量 `i` 是当前中心，`j` 是已知半径。先扩到不能扩，写 `res[i]=j`，然后从偏移 `k=1` 起，检查

```text
k + res[i-k] < j
```

这表示镜像小回文严格在当前大回文内部，可以直接复制 `res[i+k]=res[i-k]`。连续复制到第一个碰到边界的位置，再执行 `i+=k,j-=k`，保留已知部分继续扩展。

`abba` 的新串在中心 3 得到 `j=4` 后：偏移 1 有 `1+res[2]=3<4`，直接写 `res[4]=2`；偏移 2 有 `2+res[1]=3<4`，写 `res[5]=1`；偏移 3 有 `3+res[0]=4`，到边界不能直接定案，于是跳到中心 6，以半径 1 继续检查。

它与标准镜像法维护相同信息，都是线性算法。上游此外还构造长约 `2n` 的新字符串，计算完再扫描一遍转换长度；主函数使用普通 `cin/cout` 输出每个整数。

## 5. 不插分隔符的两种组织

### 5.1 分别计算奇回文与偶回文

在原串上运行两遍即可：

- `odd[i]` 为字符中心 i 的包含中心半径，长度 `2*odd[i]-1`。
- `even[i]` 为 i-1 与 i 之间的回文半长，长度 `2*even[i]`。

主例的两条数组为：

```text
odd  = [1,2,1,3,1,1,1,1]
even = [0,0,0,0,0,0,2,0]
```

输出交替写 `2*odd[i]-1` 和 `2*even[i+1]`。偶回文镜像下标与奇回文相差 1，因为中心落在字符之间；不能直接照搬同一个索引公式。

此法省掉新字符串构造、分隔符比较和统一结果后的转换扫描，仍保存约 `2n` 个半径。它没有把时间阶降到线性以下，只是减少线性阶段的常数工作。

### 5.2 用加倍坐标表示虚拟中心

还可以让内部中心 `i=1..2n-1`，题目输出位置为 `i-1`，直接维护原串回文长度 `pal`。尝试把长度加 2 时，只需比较

```text
left  = (i-pal-2)/2
right = (i+pal)/2
```

两边实际字符。扩展成功 `pal+=2`；已知最右界用加倍坐标 `i+pal` 保存。这样既不构造分隔符字符串，也不需要两遍奇偶循环，结果已经是可输出长度。

例如 `abba` 的间隙中心内部 `i=4`：先 `pal=0`，比较下标 1、2 的 `b`，变 2；再比下标 0、3 的 `a`，变 4。这里除法只能在边界检查保证合法后做，不能忽略负下标问题。

## 6. 五份源码的实际路径

### #265143：虚拟中心，算出一项就写入输出缓冲

[源码](../../selected/enumerate_palindromes/265143.cpp)的 `main` 直接 `read(0,s,N)`，以读入长度减 1 去掉末尾换行，使用静态 `res[2*N]` 保存虚拟中心结果。它维护 `longest` 与 `root_longest`，窗口内取镜像的 `min`，窗口外从 `pal=1` 开始，然后按第 5.2 节公式扩展。

这里默认值 1 与坐标奇偶性配套：最右界始终是偶数，跨出旧界的下一中心是字符中心；紧接的间隙中心会从边界内得到 0。不能脱离这个不变量把“所有中心初始化成 1”当作通用公式。

每项算出后即 `write(pal,' ')` 到 FastIO 缓冲，不再单独扫描数组转换与输出。源码仍须保留历史半径以供镜像复用。输入的单次直接读取和去末尾一个字符依赖评测的完整单行文本形式；文件前面的通用读数字函数没有参与实际输入。

### #243954：静态数组上的两次 Manacher

[源码](../../selected/enumerate_palindromes/243954.cpp)由 `main` 调用 `manacher_odd`、`manacher_even`，使用一基下标。`a[i]` 含中心，因此输出 `2a[i]-1`；`b[i]` 表示 i 前面的间隙，输出当前字符之后的间隙时要用 `b[i+1]`。

字符、奇半径、偶半径均为静态数组，省去动态向量管理；FastIO 使用 mmap 或宏条件下的缓冲，输出查表。相对上游省掉插入分隔符和结果转换，数学仍是镜像区间维护。

### #215984：原串视图与“臂长”接口

[源码](../../selected/enumerate_palindromes/215984.cpp)读 `string_view`，构造 `OY::Manacher<true,true>`，奇、偶各跑一遍。它存的 `m_odd_arm` 是中心之外的配对数，所以输出为 `2*arm+1`；`m_even_arm` 是半长，输出为 `2*arm`。

构建时对两个向量 `reserve` 后逐项 `push_back`；输入通过 LinuxIO 映射或缓冲读入视图，减少额外字符串副本。类里的任意区间回文判断 `query(left,right)` 没有被 main 调用，实际只用最大奇/偶臂长接口。

### #349293：通用范围接口包装同样的虚拟中心递推

[源码](../../selected/enumerate_palindromes/349293.cpp)由 `main → LongestPalindromeArray(S)`，返回长度 `2n-1` 的 `Vec<u32>`。递推与 #265143 的加倍坐标路线相近，但保存到零基 `res[i-1]`，显式检查镜像坐标是否正数，最后把完整向量交给 Writer 输出。

它同样省去分隔符字符串，但仍有独立结果数组输出遍历。`ONLINE_JUDGE` 决定 MmapReader 或 BasicReader；大文件中的其他字符串、排序、随机数模板没有进入这条调用链。

### #333016：一个模板循环处理两种半径

[源码](../../selected/enumerate_palindromes/333016.cpp)的 `manacher` 外层 `z=0,1` 分别处理偶/奇中心，保留 `even[n+1]` 与 `odd[n]`。其中 odd 存中心外配对数，main 按 `2*odd+1` 与 `2*even` 交替输出。

这是两个原串扫描共用一份循环结构，未创建分隔符串。读写为自定义 fread/缓冲 Scanner/Printer；不应因为它与更快提交同属“Manacher”就认定其全部额外时间在半径计算，I/O 和数组组织同样进入汇总值。

## 8. 边界、误区与实验设计

| 易错处 | 应明确的约定 |
| --- | --- |
| 只输出 n 个字符中心 | 题目还要 n-1 个间隙，共 2n-1 项 |
| 把半径直接当长度 | 含中心半径、臂长、偶半长、虚拟中心长度各不同 |
| 镜像结果全部照抄 | 碰到当前最右界只保证下界，要继续检查 |
| 奇偶镜像索引完全相同 | 间隙中心带一个下标偏移 |
| 插入任意分隔符都安全 | 分隔符必须区别于输入字母，且边界一致 |
| 最长回文长度就是回文个数 | 同中心还可能包含更短回文，本题只输出最大者 |
| 已有线性算法无法再省计算 | 输入复制、字符比较与结果扫描仍可减少 |

正确性小例包括 `a→[1]`、`ab→[1,0,1]`、`abba→[1,0,1,4,1,0,1]`，以及本页包含奇偶非平凡回文的 `abacabba`。对小串逐中心朴素扩展，能同时核对边界、奇偶和输出顺序。

还可检查字符中心长度为正奇数、间隙为非负偶数、长度不越过两端，输出对应区间确实左右对称。全相同串适合验证最坏朴素负载和 Manacher 的线性扩展；随机串多为立即失败，不能替代重复结构样例。

未来性能实验应分别计输入、半径计算和输出，并记录实际字符比较数；在固定 I/O 下比较分隔符、双数组、虚拟中心，再固定内核比较输出方式。本文只完成源码、五份哈希、数学例和链接检查，没有新增性能 benchmark 或 OJ/API 调用。
